# Organización de archivos de Megahertz

Carpetas previstas para la biblioteca del sistema. Esta estructura en GitHub **no recibe automáticamente** archivos cargados desde el navegador. La vinculación requiere implementar almacenamiento persistente y sincronización.

- `publicidad/`: tandas y avisos, separados por hora de salida.
- `separadores/`: separadores de radio.
- `jingles/`: identificaciones y jingles.
- `playlist/`: listas de música y programas.

Convención de horario: `06-00HS` equivale a `06:00 HS`. Se usa guion para compatibilidad con Windows y Mac.
