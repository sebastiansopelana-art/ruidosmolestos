VERSIÓN DE TRABAJO — REESCRITURA CINEMATOGRÁFICA
LOS CAMINOS QUE SE SEPARARON DE JETHRO TULL
FM DEL LAGO 102.5 — PRESENTA: SEBASTIÁN SOPELANA

PRESENTACIÓN GENERAL

En una banda de rock, una puerta que se cierra puede escucharse durante años. /

A veces, el público ni siquiera la oye. / Está mirando al cantante, al guitarrista que ocupa el centro del escenario, al disco que acaba de salir. // Pero detrás de ese ruido hay otros músicos juntando sus instrumentos, buscando una sala nueva, empezando otra vez. //

Esta noche vamos a seguir esas puertas. / No para averiguar quién ganó o quién perdió, sino para escuchar qué quedó sonando del otro lado. //

Esto es Ruidos Molestos. / Un insoportable programa de rock. //

CAPÍTULO 1 — JETHRO TULL
CUATRO HOMBRES Y UNA BANDA QUE TODAVÍA NO SABE QUÉ VA A SER

Londres. / 1968. //

En un club, la guitarra lleva la conversación. / El bajo se mueve con una libertad poco habitual. / La batería empuja, se adelanta, vuelve a caer sobre el pulso. // Y entonces aparece una flauta. //

No es una flauta puesta para decorar una canción. / Se mete entre las frases de guitarra, las contradice, les responde. // Si uno escuchara ese escenario sin saber quién está tocando, podría creer que son dos bandas intentando ocupar el mismo lugar. //

Una de ellas quiere tocar blues. / La otra todavía no tiene nombre para lo que está buscando. //

El guitarrista es **MICK ABRAHAMS** (MIK ÉIBRAMS). / El muchacho de la flauta es **IAN ANDERSON** (ÍAN ÁNDERSON). / Detrás están **GLENN CORNICK** (GLEN CÓRNIK), en el bajo, y **CLIVE BUNKER** (CLAIV BÁNKER), en la batería. //

Todavía no son la institución que después va a llenar teatros y aparecer en las tapas de las revistas. / Son cuatro músicos tratando de hacerse escuchar en una Inglaterra donde cada semana surge un grupo nuevo y casi todos parecen querer demostrar cuánto blues norteamericano llevan en la sangre. //

Hay un detalle que explica mucho de aquel tiempo: la banda ni siquiera había tenido siempre el mismo nombre. / Para conseguir actuaciones, había pasado por distintas denominaciones. // Lo importante era entrar al club, subir los equipos y tocar. //

Cuando finalmente graban su primer álbum, eligen un título que parece escrito desde el futuro: **THIS WAS**. / «Esto fue». //

Escuchalo con atención. / No es todavía el Jethro Tull que va a llevar el rock hacia formas más complejas. / Es una banda de blues británico con una personalidad que ya empieza a desbordar sus propias paredes. //

Abrahams encuentra su lugar en la guitarra eléctrica. / Anderson empieza a buscar salidas que no dependen de ella. // No hace falta imaginar gritos ni portazos para entender la distancia. / La diferencia está en lo que cada uno quiere tocar mañana. //

A fines de 1968, Abrahams se va. //

Pensá en el momento siguiente. / La banda tiene que encontrar otro guitarrista. / Y el guitarrista que se fue tiene que encontrar otra banda. // Desde afuera parece un solo movimiento. / En realidad son dos historias que empiezan a correr en direcciones distintas. //

**MARTIN BARRE** (MÁRTIN BAR) termina ocupando el lugar de la guitarra. / Jethro Tull cambia de piel. / Llegan **STAND UP** y **BENEFIT**. / La música se aleja de la ortodoxia del blues, sin perder del todo su aspereza. //

Pero la formación original todavía guarda otras despedidas. //

En 1970 se va Cornick. / El bajo que había conversado con la guitarra y la flauta ya no va a estar allí. // En 1971, después de **AQUALUNG**, se aleja Bunker. / También él se lleva algo que ningún reemplazante puede copiar exactamente: la manera en que había aprendido a respirar junto a los otros tres. //

Y ahora aparece la pregunta que va a mover todo el programa. //

¿Qué hacen tres músicos cuando la banda que ayudaron a construir sigue adelante sin ellos? //

Abrahams no se queda esperando. / Cornick tampoco. / Y Bunker, unos años más tarde, va a encontrarse con alguien que todavía no conocemos. //

La historia de Jethro Tull sigue. / La nuestra sale por la puerta lateral. //

MÚSICA DEL CAPÍTULO 1 — BLODWYN PIG
1. Dear Jill — El blues lento permite escuchar la expresividad que Abrahams quiso conservar.
2. It's Only Love — La guitarra lleva al frente el pulso directo de su nuevo grupo.
3. The Modern Alchemist — Los vientos de Lancaster empujan la música fuera del blues más convencional.
4. See My Way — La banda exhibe la energía con la que buscó identidad propia.

CAPÍTULO 2 — BLODWYN PIG Y THE MICK ABRAHAMS BAND
LA GUITARRA QUE NO QUISO CAMBIAR DE IDIOMA

Inglaterra. / 1969. //

Una guitarra vuelve a sonar, pero esta vez no tiene que discutir con el futuro de Jethro Tull. //

**MICK ABRAHAMS** conoce bien la pregunta que lo va a perseguir: por qué dejó una banda que estaba empezando a crecer. / Pero hay una respuesta más interesante que cualquier entrevista. // Está en el sonido de **BLODWYN PIG** (BLÓDUIN PIG). //

Abrahams no se marcha para tocar menos. / Se marcha para tocar de otra manera. / Quiere un blues que pueda estirarse sobre el escenario, con una guitarra que tenga espacio para respirar. //

Y sin embargo, el músico que se sienta a su lado no es precisamente un guardián de las reglas. //

Se llama **JACK LANCASTER** (YAK LÁNCASTER). / Toca instrumentos de viento. / Saxofones, flauta. / Donde la guitarra parece avanzar por un camino conocido, Lancaster abre una curva. //

El bajo de **ANDY PYLE** (ÁNDI PAIL) y la batería de **RON BERG** (RON BERG) sostienen una banda que tiene músculo para tocar fuerte y oído para cambiar de dirección. //

En 1969 aparece **AHEAD RINGS OUT**. //

El título tiene algo de desafío. / La música también. // Hay blues, pero los vientos no obedecen siempre a la guitarra. / A veces la empujan hacia el jazz. / A veces le dejan todo el espacio. // El grupo no es una versión reducida de Jethro Tull. / Es otra conversación. //

Un año después llega **GETTING TO THIS**. / Dos discos en un tiempo muy corto. / Grabaciones, actuaciones, expectativas. / La maquinaria de una banda en movimiento. //

Pero tener una idea clara de la música no significa que todos quieran seguir el mismo recorrido. // La formación cambia. / Abrahams se aleja de aquel proyecto y continúa su camino con otros músicos. //

Ahí aparece **THE MICK ABRAHAMS BAND**. / No es una nota al pie. / Es otro intento de sostener la voz de la guitarra después de que la primera banda propia también dejó de ser un lugar estable. //

Escuchá lo que significa ese movimiento. / Abrahams había salido de Jethro Tull porque necesitaba su música. / Después construyó Blodwyn Pig. / Y cuando tampoco esa formación permaneció intacta, volvió a poner su nombre al frente. //

No hay una gran escena de triunfo que cierre este capítulo. / Hay algo más difícil de contar: la insistencia. //

Y hay un nombre que no conviene olvidar. / **JACK LANCASTER**. //

Porque mientras Abrahams sigue su camino, Lancaster también va a continuar tocando. / Y varios años después va a encontrarse con un baterista de la primera formación de Jethro Tull. //

Una línea que parecía terminar en 1968 todavía no terminó. //

MÚSICA DEL CAPÍTULO 2 — THE MICK ABRAHAMS BAND
1. Greyhound Bus — Presenta el nuevo recorrido del guitarrista bajo su propio nombre.
2. Why Do You Do Me This Way — Recupera el filo y el pulso del blues-rock que lo identificaba.
3. Seasons — Permite escuchar otra faceta de su escritura y su manera de tocar.
4. You'll Never Get It From Me — Cierra el recorrido por su etapa posterior a Blodwyn Pig.

CAPÍTULO 3 — WILD TURKEY
EL BAJISTA QUE TUVO QUE VOLVER AL PRINCIPIO

Inglaterra. / 1970. //

Imaginá que desaparece el bajo de una canción. / La guitarra sigue. / La batería sigue. / La voz todavía está ahí. // Pero de pronto falta el piso. //

Eso es lo que hace un buen bajista: sostiene una música incluso cuando el público no está mirando sus manos. //

**GLENN CORNICK** lo había hecho desde los primeros tiempos de Jethro Tull. / Su instrumento no se limitaba a marcar las notas fundamentales. / Se movía entre la batería y la guitarra, encontraba huecos, proponía respuestas. //

Y ahora está afuera. //

La banda continúa. / Los discos siguen llegando. / El nombre Jethro Tull se vuelve cada vez más grande. // Pero Cornick tiene que resolver algo bastante menos espectacular: con quién va a tocar la semana siguiente, qué canciones van a ensayar, dónde van a conseguir actuaciones. //

No se queda inmóvil. / Forma **WILD TURKEY** (UÁILD TÉRKI). //

El nombre tiene algo de animal difícil de domesticar. / La música también busca un lugar distinto. / Sin la flauta de Anderson al frente y sin el peso de la identidad de Jethro Tull, las guitarras pueden avanzar con otra fuerza. //

En 1971 aparece **BATTLE HYMN**. //

No es la obra de un músico intentando borrar su pasado. / Es el trabajo de alguien que conoce el valor de una sección rítmica y quiere levantar otra banda alrededor de canciones nuevas. // El rock se endurece, pero todavía conserva la memoria del blues británico. //

Un año después llega **TURKEY**. //

Y acá conviene mirar el calendario. / Estamos en 1972. / El rock cambia de sonido a una velocidad feroz. / Los grupos que parecían destinados a durar una década a veces no sobreviven a dos discos. / Las formaciones se mueven. / Las oportunidades no alcanzan para todos. //

Wild Turkey atraviesa esos cambios sin convertirse en una banda de estadios. // Pero reducirla a lo que no consiguió sería perderse lo que sí dejó grabado. //

Escuchá el bajo de Cornick en este nuevo paisaje. / Ya no está dialogando con la flauta de Anderson. / Ahora sostiene canciones que tienen otras urgencias. / El músico es el mismo. / El lugar que ocupa es completamente distinto. //

La banda tendrá otras etapas y regresos. / Pero la escena decisiva está acá, al comienzo: un hombre sale de un grupo en ascenso y decide construir el siguiente desde cero. //

No vuelve a empezar porque haya olvidado cómo tocar. / Vuelve a empezar porque sabe hacerlo. //

MÚSICA DEL CAPÍTULO 3 — WILD TURKEY
1. Battle Hymn — La primera declaración de identidad del grupo de Cornick.
2. Butterfly — Muestra su costado melódico sin perder el pulso del rock.
3. Twelve Streets of Cobbled Black — Deja escuchar la ambición de sus arreglos.
4. Dulwich Fox — Devuelve al oyente al sonido del primer álbum, Battle Hymn.

CAPÍTULO 4 — AVIATOR
DOS CAMINOS EN LA MISMA HABITACIÓN

Inglaterra. / 1979. //

Pasaron once años desde aquel primer disco de Jethro Tull. //

El paisaje cambió. / El punk sacudió a la industria. / La nueva ola ocupa espacio en las radios. / Los músicos que habían pasado los años sesenta buscando nuevas formas para el blues ahora trabajan en un mundo que parece tener mucha menos paciencia. //

En ese escenario aparece una banda llamada **AVIATOR** (ÉIVIEITOR). //

Detrás de la batería está **CLIVE BUNKER**. / Sí, el mismo que había tocado en la primera formación de Jethro Tull y que había dejado el grupo después de Aqualung. //

Entre los instrumentos de viento está **JACK LANCASTER**. / El mismo que había acompañado a Mick Abrahams en Blodwyn Pig. //

Detenete un segundo en ese encuentro. //

Bunker y Lancaster no habían sido compañeros en Jethro Tull. / Lancaster nunca perteneció a aquella banda. // Pero ambos llegan a esta habitación por caminos que arrancan de la misma separación. //

Uno viene directamente de la primera formación. / El otro viene de la banda que fundó el guitarrista que se fue. //

Con ellos están **MICK ROGERS** (MIK RÓYERS), en guitarra, y **JOHN G. PERRY** (YON YI PÉRI), en bajo. //

No forman una banda para reconstruir el sonido de 1968. / La música de Aviator mira hacia otro lado: rock con arreglos amplios, cruces con el jazz, instrumentos que se responden sin pedir permiso. //

En 1979 publican **AVIATOR**. / En 1980 llega **TURBULENCE**, con cambios en la formación. //

La vida del grupo es breve. / Y tal vez por eso resulta tan reveladora. // No hay una larga carrera que tape los detalles. / Hay un encuentro preciso entre músicos que ya conocen los escenarios, los estudios y las despedidas. //

Ahora volvamos por un instante a 1968. //

La guitarra de Abrahams. / El bajo de Cornick. / La batería de Bunker. / La flauta de Anderson. //

Cuatro instrumentos que todavía intentaban descubrir si podían hablar el mismo idioma. //

De esa primera conversación salieron discos, cambios de formación y bandas nuevas. / Blodwyn Pig. / The Mick Abrahams Band. / Wild Turkey. / Aviator. //

Lo que parecía una sola banda separándose terminó siendo una red de músicos que siguieron encontrándose en otros escenarios. //

Y aquella puerta lateral, la que parecía conducir hacia afuera de la historia, terminó abriendo otra sala. //

MÚSICA DEL CAPÍTULO 4 — AVIATOR
1. Your Loving Is My Home — Presenta la faceta de canción del grupo.
2. Keep Your Heart Right — Permite escuchar la interacción de sus músicos.
3. Evil Eye — Muestra su búsqueda instrumental más intensa.
4. Way of the World — Cierra con el repertorio que figura en la selección musical cargada para el programa.

CIERRE GENERAL

Al principio escuchamos una puerta. / Una salida que, vista desde el escenario, parecía definitiva. //

Después encontramos otra guitarra. / Otro bajo. / Otra batería. / Y, muchos años más tarde, dos músicos que habían recorrido caminos distintos tocando en una misma banda. //

Quizá por eso conviene escuchar también a los que se fueron. / No para detenernos en la despedida, sino para descubrir todo lo que siguió sonando después. //

Soy Sebastián Sopelana. / Esto fue Ruidos Molestos. //

La historia llegó a su fin, el ROCK por suerte, no. //

NOTA DE PRODUCCIÓN — NO LEER AL AIRE
Esta es una primera reescritura de estructura y tono, NO la versión extensa definitiva de aproximadamente 50 páginas.
