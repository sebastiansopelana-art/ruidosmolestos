CAPÍTULO 1 — JETHRO TULL
LA BANDA QUE CAMBIÓ DE PIEL

LONDRES, 1968. / EL BLUES BRITÁNICO ESTABA EN TODAS PARTES. // EN LOS CLUBES HABÍA GUITARRISTAS TRATANDO DE HACER SONAR SUS INSTRUMENTOS COMO SI HUBIERAN NACIDO EN CHICAGO. / PERO EN MEDIO DE AQUELLA MULTITUD APARECIÓ UN MUCHACHO QUE NO QUERÍA COMPETIR CON LOS GUITARRISTAS. // SE LLAMABA IAN ANDERSON. / Y LLEVABA UNA FLAUTA. // NO ERA EL INSTRUMENTO QUE SE ESPERABA EN UNA BANDA DE ROCK. / TAMPOCO ERA EL HOMBRE QUE UNO IMAGINABA AL FRENTE DE UN GRUPO QUE TODAVÍA BUSCABA SU IDENTIDAD. //

JETHRO TULL NO NACIÓ COMO UNA INSTITUCIÓN. / NACIÓ COMO UNA BANDA QUE NECESITABA TRABAJAR. // LOS NOMBRES CAMBIABAN EN LOS CARTELES, LOS CONTRATOS ERAN MODESTOS Y LA MÚSICA SE HACÍA EN LOS ESCENARIOS ANTES DE SABER QUÉ FUTURO TENDRÍA. // ANDERSON, EL GUITARRISTA MICK ABRAHAMS, EL BAJISTA GLENN CORNICK Y EL BATERISTA CLIVE BUNKER FUERON LA FORMACIÓN QUE GRABÓ THIS WAS. // UN TÍTULO EXTRAÑO PARA UN PRIMER DISCO: ESTO FUE. // COMO SI YA SUPIERAN QUE AQUEL SONIDO NO DURARÍA PARA SIEMPRE. //

ABRAHAMS QUERÍA UN BLUES MÁS DIRECTO. / ANDERSON EMPEZABA A IMAGINAR OTRA COSA: MÚSICA CON GIROS INESPERADOS, ELEMENTOS FOLCLÓRICOS, MELODÍAS QUE NO OBEDECIERAN A LAS REGLAS DE UN SOLO GÉNERO. // LOS DOS TENÍAN RAZONES MUSICALES. / EL PROBLEMA ERA QUE NO CABÍAN CÓMODAMENTE EN LA MISMA BANDA. // A FINES DE 1968, ABRAHAMS SE FUE. // NO FUE EL FINAL DE JETHRO TULL. / FUE EL COMIENZO DE UNA CADENA DE HISTORIAS. //

MARTIN BARRE TERMINÓ OCUPANDO EL LUGAR DE LA GUITARRA. / JETHRO TULL EMPEZÓ A DEJAR ATRÁS EL BLUES ORTODOXO Y A CONSTRUIR UN IDIOMA PROPIO. // STAND UP Y BENEFIT ABRIERON CAMINO A UNA IDENTIDAD CADA VEZ MÁS AMBICIOSA. / PERO ESA TRANSFORMACIÓN TAMBIÉN EXIGÍA CAMBIOS HUMANOS. // GLENN CORNICK DEJÓ LA BANDA EN 1970. / CLIVE BUNKER LO HARÍA EN 1971, DESPUÉS DE AQUALUNG. // CADA SALIDA ERA UNA PÉRDIDA PARA EL GRUPO Y UNA POSIBILIDAD PARA OTRO. //

PENSÁ EN ESOS MÚSICOS MIRANDO DESDE AFUERA EL ÉXITO DE UNA BANDA QUE HABÍAN AYUDADO A FUNDAR. / ES FÁCIL CONTAR ESTA HISTORIA DESDE LOS DISCOS DE ORO. / MÁS DIFÍCIL ES IMAGINAR EL MOMENTO EN QUE UNO TIENE QUE DECIDIR SI SIGUE TOCANDO LA MÚSICA DE OTRO O SE ANIMA A CONSTRUIR LA SUYA. // ESTA NOCHE VAMOS A ESCUCHAR QUÉ PASÓ CON LOS QUE ELIGIERON IRSE.

UNA ESCENA ANTES DE LA DESPEDIDA

EL LOCAL ESTÁ LLENO DE HUMO. / LA BATERÍA DE **CLIVE BUNKER** NO ESPERA A NADIE. / **GLENN CORNICK** HACE CAMINAR EL BAJO POR DEBAJO DE LA GUITARRA DE **MICK ABRAHAMS**. // EL BLUES TODAVÍA MANDA, PERO HAY ALGO QUE SE LE ESCAPA. / **IAN ANDERSON** LEVANTA LA FLAUTA Y LA CANCIÓN CAMBIA DE CENTRO. //

NO HACE FALTA INVENTAR UNA PELEA EN UN CAMARÍN PARA ENTENDER LO QUE OCURRE. / A VECES LA DISCUSIÓN ESTÁ EN LOS ARREGLOS. // UN MÚSICO QUIERE ESTIRAR EL SOLO DE GUITARRA. / OTRO QUIERE QUE LA CANCIÓN SE VAYA HACIA UN LUGAR QUE TODAVÍA NO TIENE NOMBRE. // Y LOS OTROS DOS TIENEN QUE SOSTENER A AMBOS SIN QUE LA MÚSICA SE ROMPA. //

EN 1968, **THIS WAS** NO ES UNA PROMESA DE LO QUE VENDRÁ. / ES EL RETRATO DE LO QUE ESOS CUATRO HOMBRES PUEDEN HACER JUNTOS. // EL DISCO TIENE EL PESO DEL BLUES, PERO TAMBIÉN UNA INQUIETUD QUE NO SE DEJA ENCASILLAR. / ESCUCHÁ CÓMO LA FLAUTA ENTRA Y SALE DE LAS FRASES DE GUITARRA. / ESCUCHÁ EL BAJO. / NO ESTÁ AHÍ PARA RELLENAR LOS HUECOS: PARTICIPA DE LA CONVERSACIÓN. //

CUANDO ABRAHAMS SE VA, LA HISTORIA OFICIAL SIGUE A LA BANDA QUE CONSIGUE FAMA. / LA OTRA HISTORIA CAMINA POR UNA CALLE DISTINTA. // LA DE UN HOMBRE QUE TIENE QUE VOLVER A ENSAYAR CON DESCONOCIDOS, VOLVER A EXPLICAR QUÉ MÚSICA QUIERE HACER, VOLVER A CONSEGUIR ESCENARIOS. //

Y TODAVÍA FALTAN DOS DESPEDIDAS. / CORNICK TOCA EN LOS DISCOS QUE LLEVAN A JETHRO TULL MÁS ALLÁ DE SU PRIMER BLUES. / BUNKER DEJA SU MARCA EN **AQUALUNG**. // CUANDO CADA UNO SE ALEJA, NO DESAPARECE LA EXPERIENCIA QUE LLEVA EN LAS MANOS. / SE LA LLEVA A OTRA SALA DE ENSAYO. //

CAPÍTULO 2 — BLODWYN PIG
EL GUITARRISTA QUE NO QUISO RENUNCIAR AL BLUES

MICK ABRAHAMS NO SE HABÍA IDO DE JETHRO TULL PARA DESAPARECER. // TENÍA UNA IDEA MUY CLARA DEL SONIDO QUE QUERÍA. / GUITARRA CON FILO, BLUES SIN DISFRAZ Y UNA BANDA QUE PUDIERA RESPIRAR EN EL ESCENARIO. // ASÍ NACIÓ BLODWYN PIG. //

EN EL CENTRO ESTABA SU GUITARRA. / PERO AL LADO APARECIÓ ALGO MENOS PREVISIBLE: JACK LANCASTER, UN MÚSICO CAPAZ DE CAMBIAR ENTRE SAXOFONES Y FLAUTA Y DE EMPUJAR UNA CANCIÓN HACIA UN TERRITORIO DISTINTO. // LA SECCIÓN RÍTMICA, CON ANDY PYLE Y RON BERG EN LA FORMACIÓN CLÁSICA, LE DABA PESO A UN GRUPO QUE NO QUERÍA SER UNA COPIA DE JETHRO TULL. //

EL PRIMER ÁLBUM, AHEAD RINGS OUT, APARECIÓ EN 1969. / Y TENÍA UNA VIRTUD QUE NO SIEMPRE SE CONSIGUE EN UN DEBUT: SONABA COMO UNA BANDA QUE SABÍA EXACTAMENTE LO QUE QUERÍA DECIR. // EL BLUES SE CRUZABA CON EL JAZZ, EL HUMOR CON LA RABIA, LAS PIEZAS INSTRUMENTALES CON CANCIONES MÁS TERRENALES. // ABRAHAMS NO HABÍA ABANDONADO LA EXPERIMENTACIÓN. / HABÍA ABANDONADO UNA FORMA DE ENTENDERLA. //

EN 1970 LLEGÓ GETTING TO THIS. / EL GRUPO TENÍA MATERIAL, IDENTIDAD Y MÚSICOS SOBRADOS. / PERO UNA BANDA NO ES SOLAMENTE UN DISCO. // HAY AGENDAS, CANSANCIO, EXPECTATIVAS, PERSONALIDADES Y UNA INDUSTRIA QUE SIEMPRE QUIERE SABER QUÉ VIENE DESPUÉS. // ABRAHAMS SE ALEJÓ DE LA FORMACIÓN ORIGINAL Y EL PROYECTO CAMBIÓ. / LOS MÚSICOS SIGUIERON OTROS CAMINOS. //

JACK LANCASTER ES UNA DE LAS CLAVES SECRETAS DE NUESTRO PROGRAMA. // PORQUE SU NOMBRE VOLVERÁ A APARECER EN EL ÚLTIMO BLOQUE. / Y CUANDO ESO PASE, VA A ESTAR SENTADO JUNTO A OTRO HOMBRE QUE TAMBIÉN HABÍA SALIDO DE JETHRO TULL. //

ESTA HISTORIA NO TRATA DE QUIÉN TENÍA RAZÓN EN UNA DISCUSIÓN DE 1968. // TRATA DE UN GUITARRISTA QUE PREFIRIÓ ARRIESGAR UN LUGAR EN UNA BANDA PROMETEDORA ANTES QUE RENUNCIAR A SU MANERA DE TOCAR. // Y A VECES, EN EL ROCK, ESA DECISIÓN VALE MÁS QUE UNA CARRERA PREDECIBLE.

LA OTRA PUERTA

IMAGINÁ EL PRIMER ENSAYO DE UNA BANDA NUEVA. / NO HAY UN PÚBLICO QUE TE CONOZCA, NO HAY UN NOMBRE QUE TE PROTEJA. / HAY AMPLIFICADORES, CABLES, ALGUNA IDEA A MEDIO TERMINAR Y UN SILENCIO INCÓMODO ANTES DE CONTAR CUATRO. //

**MICK ABRAHAMS** LLEGA CON UNA VENTAJA Y UNA CARGA. / SABE TOCAR, SABE QUÉ SONIDO BUSCA, PERO TODOS VAN A PREGUNTARLE POR LA BANDA QUE ACABA DE DEJAR. // **BLODWYN PIG** ES SU RESPUESTA. / NO EN UNA ENTREVISTA. / EN EL VOLUMEN DE UNA GUITARRA. //

EL NOMBRE DE **JACK LANCASTER** MERECE DETENERSE. / NO HABÍA SIDO INTEGRANTE DE JETHRO TULL. / SU CONEXIÓN CON AQUELLA HISTORIA NACE AQUÍ, TOCANDO CON ABRAHAMS. // Y ESE DETALLE ES IMPORTANTE, PORQUE MÁS ADELANTE VA A ENCONTRARSE CON UN BATERISTA QUE SÍ HABÍA ESTADO EN LA PRIMERA FORMACIÓN. //

EN **AHEAD RINGS OUT**, DE 1969, LOS INSTRUMENTOS DE VIENTO NO ESTÁN PUESTOS PARA ADORNAR LA GUITARRA. / LA DISCUTEN. / A VECES LA SIGUEN, A VECES LE CAMBIAN EL HUMOR A LA CANCIÓN. // ES UN BLUES-ROCK QUE NO TIENE MIEDO DE DEJAR UNA PUERTA ABIERTA AL JAZZ. //

LA SEGUNDA ENTREGA, **GETTING TO THIS**, APARECE EN 1970. / DOS DISCOS EN POCO TIEMPO. / UNA BANDA QUE TRABAJA RÁPIDO. // PERO PUBLICAR DISCOS NO GARANTIZA QUE CUATRO PERSONAS QUIERAN SEGUIR TOMANDO LAS MISMAS DECISIONES. // EL GRUPO CAMBIA, ABRAHAMS SE ALEJA, Y LA MÚSICA VUELVE A DISPERSARSE ENTRE OTROS PROYECTOS. //

ESCUCHÁ ESTOS CUATRO TEMAS SIN PENSAR EN EL ÉXITO POSTERIOR DE JETHRO TULL. / POR UN RATO, DEJÁ AFUERA ESA COMPARACIÓN. // ACÁ HAY UNA BANDA CON SU PROPIO PULSO. / Y UNA HISTORIA QUE VA A VOLVER A TOCAR NUESTRA PUERTA EN EL CUARTO BLOQUE. //

CAPÍTULO 3 — WILD TURKEY
EL BAJISTA QUE QUISO VOLVER A EMPEZAR

GLENN CORNICK TENÍA UNA PRESENCIA IMPOSIBLE DE CONFUNDIR. / EN LOS PRIMEROS JETHRO TULL SU BAJO NO ERA UNA SOMBRA DETRÁS DE LA GUITARRA. / CAMINABA, EMPUJABA, DISCUTÍA CON LOS DEMÁS INSTRUMENTOS. // HABÍA AYUDADO A CONSTRUIR LA PERSONALIDAD DE UNA BANDA QUE EMPEZABA A SER CONOCIDA FUERA DE INGLATERRA. // Y SIN EMBARGO, EN 1970, SU HISTORIA ALLÍ TERMINÓ. //

PARA MUCHOS MÚSICOS, SALIR DE UN GRUPO EN ASCENSO ES UNA CONDENA AL OLVIDO. / CORNICK NO LO ACEPTÓ. // ARMÓ WILD TURKEY. / EL NOMBRE SONABA COMO UNA DECLARACIÓN: ALGO SALVAJE, POCO DOMESTICADO, QUE NO TENÍA INTENCIONES DE PEDIR PERMISO. //

EL PRIMER DISCO, BATTLE HYMN, SALIÓ EN 1971. / ERA ROCK BRITÁNICO CON RAÍCES DE BLUES, GUITARRAS ROBUSTAS Y UNA PERSONALIDAD DISTINTA DE LA DE JETHRO TULL. // AQUÍ NO HABÍA QUE COMPETIR CON LA FLAUTA DE ANDERSON NI CON UNA VISIÓN CADA VEZ MÁS PROGRESIVA. / EL GRUPO PODÍA SEGUIR LA CANCIÓN HASTA DONDE LA LLEVARA SU PROPIA ENERGÍA. //

PERO EL MUNDO DEL ROCK NO REPARTÍA EL ÉXITO DE MANERA JUSTA. // UNA BANDA PODÍA TENER BUENAS CANCIONES, TOCAR CON CONVICCIÓN Y AUN ASÍ NO CONSEGUIR EL LUGAR QUE MERECÍA. // WILD TURKEY PUBLICÓ TURKEY EN 1972. / LA FORMACIÓN CAMBIÓ, LOS CAMINOS SE COMPLICARON Y LA PRIMERA ETAPA SE APAGÓ SIN CONVERTIRSE EN UNA LEYENDA DE ESTADIOS. //

ESO NO LE QUITA VALOR A LO QUE HICIERON. // AL CONTRARIO. / NOS PERMITE ESCUCHAR UN TIPO DE ROCK QUE NO ESTÁ OBLIGADO A RESPONDER A UNA HISTORIA DE ÉXITO. // HAY ALGO MUY HONESTO EN ESOS DISCOS: MÚSICOS QUE TOCAN PORQUE TODAVÍA NECESITAN DECIR ALGO. //

CORNICK VOLVERÍA A REVISITAR EL NOMBRE WILD TURKEY EN AÑOS POSTERIORES. / PERO LO QUE NOS IMPORTA ESTA NOCHE ES AQUEL PRIMER IMPULSO. // UN BAJISTA SE QUEDA SIN SU BANDA Y EN LUGAR DE ESPERAR QUE LO LLAMEN, ARMA OTRA. // EN LA HISTORIA DEL ROCK, ESO PASÓ MILES DE VECES. / POCAS QUEDARON TAN CLARAMENTE CONECTADAS A UNA MISMA FAMILIA MUSICAL.

EL BAJO NO SE QUEDA QUIETO

EN UNA FOTOGRAFÍA DE UNA BANDA, EL BAJISTA SUELE ESTAR UN POCO CORRIDO. / NO SIEMPRE OCUPA EL CENTRO. / PERO SACALO DE UNA GRABACIÓN Y DE PRONTO TODO SE VIENE ABAJO. // **GLENN CORNICK** PERTENECÍA A ESA CLASE DE MÚSICOS QUE HACEN QUE EL RESTO PUEDA ARRIESGARSE. //

LA SALIDA DE JETHRO TULL NO LO CONVIERTE AUTOMÁTICAMENTE EN EL LÍDER DE UNA BANDA EXITOSA. / LO DEVUELVE AL PRINCIPIO: BUSCAR COMPAÑEROS, PROBAR MATERIAL, ELEGIR UN SONIDO Y CONVENCER A ALGUIEN DE QUE VALE LA PENA ESCUCHARLO. //

EN 1971 APARECE **BATTLE HYMN**. / HAY UN ROCK DE GUITARRAS PESADAS, PERO TAMBIÉN PASAJES DONDE EL GRUPO PREFIERE LA MELODÍA A LA FUERZA. // LA VOZ, EL BAJO Y LAS GUITARRAS NO ESTÁN IMITANDO LA FLAUTA DE ANDERSON. / ESTÁN CONSTRUYENDO UNA CASA DIFERENTE CON ALGUNOS MATERIALES QUE VIENEN DEL MISMO BARRIO. //

EL DISCO SIGUIENTE, **TURKEY**, LLEGA EN 1972. / EL CAMBIO DE DÉCADA SE NOTA EN EL SONIDO. / EL BLUES BRITÁNICO QUE HABÍA SIDO EL PUNTO DE PARTIDA YA CONVIVE CON EL ROCK PESADO Y CON CANCIONES MÁS ABIERTAS. // NO TODOS LOS GRUPOS ENCUENTRAN SU LUGAR EN ESA TRANSICIÓN. //

PERO NO HAY QUE CONFUNDIR FALTA DE FAMA CON FALTA DE HISTORIA. / EN LOS SURCOS DE ESTOS DISCOS ESTÁ LA RESPUESTA DE UN MÚSICO A UNA PREGUNTA DIFÍCIL: ¿QUÉ HACÉS CUANDO EL GRUPO QUE AYUDASTE A LEVANTAR SIGUE SU CAMINO SIN VOS? // CORNICK CONTESTÓ TOCANDO. //

CAPÍTULO 4 — AVIATOR

EL PROYECTO TUVO UNA VIDA BREVE Y UNA SEGUNDA GRABACIÓN, TURBULENCE, EN 1980, CON CAMBIOS EN LA FORMACIÓN. // Y AQUÍ ES DONDE NUESTRA HISTORIA ENCUENTRA SU FINAL. // NO EN UN GRAN ESTADIO. / NO EN UN DISCO MULTIPLATINO. / SINO EN LA POSIBILIDAD DE QUE DOS MÚSICOS QUE HABÍAN ESTADO EN LOS MÁRGENES DE UNA MISMA HISTORIA TERMINARAN CONSTRUYENDO ALGO JUNTOS. //

DE JETHRO TULL SALIÓ ABRAHAMS Y NACIÓ BLODWYN PIG. / SALIÓ CORNICK Y NACIÓ WILD TURKEY. / SALIÓ BUNKER Y, AÑOS DESPUÉS, SU CAMINO SE CRUZÓ CON EL DE LANCASTER EN AVIATOR. // CUATRO BANDAS. / UNA RED DE DECISIONES. // LO QUE PARECÍA UNA SERIE DE DESPEDIDAS ERA, EN REALIDAD, UNA CADENA DE NUEVOS COMIENZOS.

LOS CAMINOS VUELVEN A CRUZARSE

AHORA LA FECHA ES 1979. / EN LOS ESCENARIOS BRITÁNICOS YA NO SE DISCUTE EXACTAMENTE LO MISMO QUE EN 1968. / LAS BANDAS DE ROCK CON ARREGLOS LARGOS CONVIVEN CON UN PÚBLICO QUE ESCUCHA OTRAS URGENCIAS. // EN ESE PAISAJE APARECE **AVIATOR**. //

**CLIVE BUNKER** NO NECESITA PRESENTARSE CON EL NOMBRE DE JETHRO TULL EN LA FRENTE. / SU BATERÍA HABÍA SIDO PARTE DE UNA ETAPA FUNDACIONAL. / **JACK LANCASTER** TAMPOCO LLEGA VACÍO: TRAE EL COLOR DE LOS VIENTOS Y LA EXPERIENCIA DE BLODWYN PIG. // CON **MICK ROGERS** EN GUITARRA Y **JOHN G. PERRY** EN BAJO, LA BANDA TIENE UNA COMBINACIÓN POCO COMÚN DE TRAYECTORIAS. //

NO ES UNA REUNIÓN DE EXMIEMBROS DE JETHRO TULL: LANCASTER NUNCA FUE MIEMBRO DE ESA BANDA. / ES ALGO MÁS INTERESANTE. // ES EL PUNTO DONDE DOS RAMAS DE UNA HISTORIA TERMINAN EN LA MISMA HABITACIÓN. //

EL PRIMER DISCO, **AVIATOR**, SALE EN 1979. / AL AÑO SIGUIENTE LLEGA **TURBULENCE**, YA EN UN CONTEXTO DISTINTO. // LA VIDA DEL GRUPO ES BREVE, PERO ALCANZA PARA DEJAR UNA HUELLA: MÚSICOS QUE HABÍAN ACOMPAÑADO CAMBIOS IMPORTANTES DEL ROCK BRITÁNICO TODAVÍA TENÍAN GANAS DE BUSCAR UN SONIDO NUEVO. //

VOLVÉ MENTALMENTE A AQUEL PRIMER ESCENARIO DE 1968. / LA GUITARRA DE ABRAHAMS, EL BAJO DE CORNICK, LA BATERÍA DE BUNKER, LA FLAUTA DE ANDERSON. // NINGUNO PODÍA SABER TODAS LAS BANDAS QUE IBAN A NACER DE AQUELLA COMBINACIÓN. // AHORA ESCUCHAMOS EL ECO, PERO NO UN ECO INMÓVIL. / UN ECO QUE SIGUIÓ HACIENDO MÚSICA. //
