LOS CAMINOS QUE SE SEPARARON DE JETHRO TULL
FM DEL LAGO 102.5 — PRESENTA: SEBASTIÁN SOPELANA

PRESENTACIÓN GENERAL

En una banda de rock, una puerta que se cierra puede escucharse durante años. /

A veces, el público ni siquiera la oye. / Está mirando al cantante, al guitarrista que ocupa el centro del escenario, al disco que acaba de salir. // Pero detrás de ese ruido hay otros músicos juntando sus instrumentos, buscando una sala nueva, empezando otra vez. //

Esta noche vamos a seguir esas puertas. / No para averiguar quién ganó o quién perdió, sino para escuchar qué quedó sonando del otro lado. //

Esto es Ruidos Molestos. / Un insoportable programa de rock. //

CAPÍTULO 1 — JETHRO TULL: EL PUNTO DE PARTIDA
CUATRO HOMBRES Y UNA BANDA QUE TODAVÍA NO SABE QUÉ VA A SER

Londres. / 1968. //

En un club, la guitarra lleva la conversación. / El bajo se mueve con una libertad poco habitual. / La batería empuja, se adelanta, vuelve a caer sobre el pulso. // Y entonces aparece una flauta. //

No es una flauta puesta para decorar una canción. / Se mete entre las frases de guitarra, las contradice, les responde. // Si uno escuchara ese escenario sin saber quién está tocando, podría creer que son dos bandas intentando ocupar el mismo lugar. //

Una de ellas quiere tocar blues. / La otra todavía no tiene nombre para lo que está buscando. //

El guitarrista es **MICK ABRAHAMS** (MIK ÉIBRAMS). / El muchacho de la flauta es **IAN ANDERSON** (ÍAN ÁNDERSON). / Detrás están **GLENN CORNICK** (GLEN CÓRNIK), en el bajo, y **CLIVE BUNKER** (CLAIV BÁNKER), en la batería. //

Todavía no son la institución que después va a llenar teatros y aparecer en las tapas de las revistas. / Son cuatro músicos tratando de hacerse escuchar en una Inglaterra donde cada semana surge un grupo nuevo y casi todos parecen querer demostrar cuánto blues norteamericano llevan en la sangre. //

Hay un detalle que explica mucho de aquel tiempo: la banda ni siquiera había tenido siempre el mismo nombre. / Para conseguir actuaciones, había pasado por distintas denominaciones. // Lo importante era entrar al club, subir los equipos y tocar. //

Cuando finalmente graban su primer álbum, eligen un título que parece escrito desde el futuro: **THIS WAS**. / «Esto fue». //

Escuchalo con atención. / No es todavía el Jethro Tull que va a llevar el rock hacia formas más complejas. / Es una banda de blues británico con una personalidad que ya empieza a desbordar sus propias paredes. //

Abrahams encuentra su lugar en la guitarra eléctrica. / Anderson empieza a buscar salidas que no dependen de ella. // No hace falta imaginar gritos ni portazos para entender la distancia. / La diferencia está en lo que cada uno quiere tocar mañana. //

A fines de 1968, Abrahams se va. //

Pensá en el momento siguiente. / La banda tiene que encontrar otro guitarrista. / Y el guitarrista que se fue tiene que encontrar otra banda. // Desde afuera parece un solo movimiento. / En realidad son dos historias que empiezan a correr en direcciones distintas. //

**MARTIN BARRE** (MÁRTIN BAR) termina ocupando el lugar de la guitarra. / Jethro Tull cambia de piel. / Llegan **STAND UP** y **BENEFIT**. / La música se aleja de la ortodoxia del blues, sin perder del todo su aspereza. //

Pero la formación original todavía guarda otras despedidas. //

En 1970 se va Cornick. / El bajo que había conversado con la guitarra y la flauta ya no va a estar allí. // En 1971, después de **AQUALUNG**, se aleja Bunker. / También él se lleva algo que ningún reemplazante puede copiar exactamente: la manera en que había aprendido a respirar junto a los otros tres. //

Y ahora aparece la pregunta que va a mover todo el programa. //

¿Qué hacen tres músicos cuando la banda que ayudaron a construir sigue adelante sin ellos? //

Abrahams no se queda esperando. / Cornick tampoco. / Y Bunker, unos años más tarde, va a encontrarse con alguien que todavía no conocemos. //

La historia de Jethro Tull sigue. / La nuestra sale por la puerta lateral. //

UN POCO ANTES DE QUE TODO CAMBIE

Para entender aquella flauta hay que mirar primero la guitarra que Anderson dejó de tocar. //

Porque IAN ANDERSON también había querido ser guitarrista. / Y en la Inglaterra de mediados de los sesenta, querer tocar la guitarra era casi una obligación. // Había una generación entera persiguiendo el sonido de los discos de blues que llegaban de Estados Unidos. / Los músicos escuchaban a sus héroes, copiaban sus frases y después trataban de encontrar una voz propia en clubes pequeños, con equipos prestados y poco dinero. //

Anderson comprendió que en la guitarra había demasiados hombres extraordinarios. / Cambiar de instrumento no era simplemente una ocurrencia para llamar la atención. / Era buscar una puerta por la que todavía no hubiera entrado todo el mundo. //

Y ahí está la flauta. //

En manos de Anderson, ese instrumento deja de comportarse como se espera de él. / Hay respiraciones violentas, golpes de aire, ataques cortantes. / El cuerpo entero participa. // Sobre el escenario, la imagen también cambia: un músico que levanta una pierna, se inclina sobre el micrófono y hace de un instrumento asociado a otros ambientes una voz de rock. //

Pero al lado suyo está MICK ABRAHAMS. / Y Abrahams no necesita buscar otro idioma. // Para él, el blues ya tiene suficiente territorio por explorar. / Una nota bien sostenida puede decir más que una docena de adornos. / Una guitarra que responde a una voz puede convertir una canción sencilla en algo inolvidable. //

Esa diferencia es el motor del primer disco. //

No hay que escuchar THIS WAS como si fuera un ensayo imperfecto de lo que vendría después. / Escuchalo como una obra completa, hecha por cuatro hombres que por un instante encontraron un equilibrio. // La batería de CLIVE BUNKER tiene un movimiento nervioso. / El bajo de GLENN CORNICK se anima a contestar. / La guitarra y la flauta ocupan el primer plano sin terminar de ponerse de acuerdo sobre quién cuenta la historia. //

Y ese desacuerdo, mientras funciona, produce música extraordinaria. //

La separación de Abrahams no se explica solamente con la palabra «diferencias». / Esa palabra suele esconder lo más interesante. // Lo que está en juego es quién decide la dirección de una banda cuando todavía nadie sabe cuánto puede crecer. //

Si seguían profundizando el blues, Abrahams tenía mucho para decir. / Si iban hacia canciones de estructuras menos previsibles, Anderson veía un mundo entero por descubrir. // Elegir una dirección implicaba dejar algo atrás. //

Al salir Abrahams, la banda atraviesa la búsqueda de otro guitarrista. / MARTIN BARRE no llega como una copia del hombre anterior. / Su manera de tocar va a acompañar una transformación que se vuelve evidente en STAND UP. // La música abre ventanas al folk, a arreglos más elaborados, a una personalidad que ya no depende de la escena del blues británico. //

Pero la banda cambia por dentro al mismo tiempo que cambia por fuera. //

CORNICK vive la transición desde el bajo. / Participa de los discos que hacen crecer el nombre Jethro Tull y después se marcha. // BUNKER llega hasta AQUALUNG, uno de los álbumes decisivos de esa primera etapa, y luego también deja su lugar. //

Mirado desde una discografía, son fechas y nombres en una lista. / Mirado desde el escenario, es otra cosa. //

Un baterista aprende a reconocer el momento exacto en que su compañero va a estirar una frase. / Un bajista sabe cuándo el guitarrista está por dejar un silencio. / Eso no aparece escrito en las partituras. // Es una conversación que se construye noche tras noche. //

Cuando alguien se va, esa conversación termina. / Los que quedan aprenden otro idioma con los reemplazantes. / Y los que se marchan tienen que encontrar músicos capaces de entender el suyo. //

Esta noche vamos a seguir precisamente ese sonido que se llevan. / No el nombre que queda iluminado en el cartel, sino la música que sale por la puerta y vuelve a encenderse en otro escenario. //


EL DISCO QUE PARECE UNA DESPEDIDA

Hay algo inquietante en el título THIS WAS. / No dice «esto es». / Dice «esto fue». //

Y sin embargo, cuando se publica en 1968, Jethro Tull recién está empezando a dejar una huella en el rock británico. // La música tiene una energía de club. / Se escucha a cuatro músicos que todavía están cerca del público, de los escenarios donde cada noche hay que ganarse el derecho a volver. //

En MY SUNDAY FEELING, la banda entra con decisión. / La flauta de Anderson no parece llegada de otro género para suavizar la canción: entra a discutir con la guitarra. // En BEGGAR'S FARM, el espacio entre los instrumentos importa tanto como las notas. / Es un sonido que respira. //

Y después está el detalle que suele quedar afuera de las historias contadas demasiado rápido: ninguno de esos músicos estaba tocando con la certeza de que sus nombres serían recordados medio siglo después. //

Trabajaban. / Ensayaban. / Buscaban actuaciones. / Trataban de hacer que una banda sobreviviera. //

El éxito posterior cambia la manera en que miramos hacia atrás. / Hace que cada decisión parezca inevitable. / Pero en 1968 no hay nada inevitable. // Si Abrahams se hubiera quedado, Jethro Tull podría haber seguido siendo una banda de blues. / Si Anderson hubiera cedido su búsqueda, quizá la flauta habría terminado siendo un detalle pintoresco. // Esas posibilidades no ocurrieron. / Lo que ocurrió fue una separación. //

Y de esa separación nace la música que escucharemos esta noche. //


MÚSICA DEL CAPÍTULO 1 — BLODWYN PIG
1. Dear Jill — El blues lento permite escuchar la expresividad que Abrahams quiso conservar.
2. It's Only Love — La guitarra lleva al frente el pulso directo de su nuevo grupo.
3. The Modern Alchemist — Los vientos de Lancaster empujan la música fuera del blues más convencional.
4. See My Way — La banda exhibe la energía con la que buscó identidad propia.

CAPÍTULO 2 — BLODWYN PIG Y THE MICK ABRAHAMS BAND
LA GUITARRA QUE NO QUISO CAMBIAR DE IDIOMA

Inglaterra. / 1969. //

Una guitarra vuelve a sonar, pero esta vez no tiene que discutir con el futuro de Jethro Tull. //

**MICK ABRAHAMS** conoce bien la pregunta que lo va a perseguir: por qué dejó una banda que estaba empezando a crecer. / Pero hay una respuesta más interesante que cualquier entrevista. // Está en el sonido de **BLODWYN PIG** (BLÓDUIN PIG). //

Abrahams no se marcha para tocar menos. / Se marcha para tocar de otra manera. / Quiere un blues que pueda estirarse sobre el escenario, con una guitarra que tenga espacio para respirar. //

Y sin embargo, el músico que se sienta a su lado no es precisamente un guardián de las reglas. //

Se llama **JACK LANCASTER** (YAK LÁNCASTER). / Toca instrumentos de viento. / Saxofones, flauta. / Donde la guitarra parece avanzar por un camino conocido, Lancaster abre una curva. //

El bajo de **ANDY PYLE** (ÁNDI PAIL) y la batería de **RON BERG** (RON BERG) sostienen una banda que tiene músculo para tocar fuerte y oído para cambiar de dirección. //

En 1969 aparece **AHEAD RINGS OUT**. //

El título tiene algo de desafío. / La música también. // Hay blues, pero los vientos no obedecen siempre a la guitarra. / A veces la empujan hacia el jazz. / A veces le dejan todo el espacio. // El grupo no es una versión reducida de Jethro Tull. / Es otra conversación. //

Un año después llega **GETTING TO THIS**. / Dos discos en un tiempo muy corto. / Grabaciones, actuaciones, expectativas. / La maquinaria de una banda en movimiento. //

Pero tener una idea clara de la música no significa que todos quieran seguir el mismo recorrido. // La formación cambia. / Abrahams se aleja de aquel proyecto y continúa su camino con otros músicos. //

Ahí aparece **THE MICK ABRAHAMS BAND**. / No es una nota al pie. / Es otro intento de sostener la voz de la guitarra después de que la primera banda propia también dejó de ser un lugar estable. //

Escuchá lo que significa ese movimiento. / Abrahams había salido de Jethro Tull porque necesitaba su música. / Después construyó Blodwyn Pig. / Y cuando tampoco esa formación permaneció intacta, volvió a poner su nombre al frente. //

No hay una gran escena de triunfo que cierre este capítulo. / Hay algo más difícil de contar: la insistencia. //

Y hay un nombre que no conviene olvidar. / **JACK LANCASTER**. //

Porque mientras Abrahams sigue su camino, Lancaster también va a continuar tocando. / Y varios años después va a encontrarse con un baterista de la primera formación de Jethro Tull. //

Una línea que parecía terminar en 1968 todavía no terminó. //

DOS DISCOS, UNA GUITARRA Y MUCHAS SALIDAS

Volvamos a 1969. //

El nombre de BLODWYN PIG empieza a circular mientras Jethro Tull sigue creciendo. / La comparación es inevitable, pero no sirve demasiado para escuchar lo que pasa en los discos. // Abrahams no está tratando de ganarle una carrera a Anderson. / Está construyendo un lugar donde su guitarra no tenga que pedir permiso para tocar blues. //

Lo curioso es que ese lugar no termina siendo conservador. //

JACK LANCASTER llega con un arsenal de instrumentos de viento y una manera de pensar la música que no se detiene en los doce compases. // Hay pasajes donde el saxofón empuja a la guitarra. / Otros donde la flauta se mueve sobre un ritmo que podría haber salido de un club de jazz. // La tensión que había dividido a Jethro Tull reaparece transformada: esta vez los caminos distintos consiguen convivir dentro de la misma banda. //

Escuchá DEAR JILL. //

No hace falta imaginar luces de colores ni una multitud gritando. / Basta con seguir la manera en que la guitarra sostiene el clima. // Hay espacio entre las notas. / Hay una voz que no intenta impresionar por la fuerza. / Hay una banda que entiende cuándo conviene bajar el volumen. //

Después escuchá IT'S ONLY LOVE. / El cuerpo cambia. / El ataque de la guitarra se vuelve más frontal. // El mismo grupo puede moverse entre esos dos mundos sin perder su personalidad. //

Eso explica por qué AHEAD RINGS OUT llamó la atención: no era únicamente el disco del guitarrista que había dejado Jethro Tull. / Era una banda que tenía algo propio para decir. //

Y entonces llega la segunda grabación, GETTING TO THIS. //

En los años sesenta y setenta, una banda no podía quedarse demasiado tiempo quieta. / Había que tocar, grabar, viajar, volver a ensayar. // El éxito de una noche no pagaba automáticamente la siguiente. / Cada disco abría posibilidades y también nuevas discusiones sobre qué hacer después. //

En ese ritmo acelerado, las formaciones podían cambiar antes de que el público llegara a conocerlas bien. / Blodwyn Pig no fue una excepción. //

Abrahams sigue adelante con su nombre. / Lo que cambia no es la importancia de la guitarra, sino el marco que la rodea. //

THE MICK ABRAHAMS BAND permite escuchar esa insistencia desde otro ángulo. / Ya no hay necesidad de explicar cada canción como una respuesta a Ian Anderson. / La música tiene que sostenerse sola. //

Y ahí aparece una escena que el rock repite muchas veces, aunque pocas veces la cuenta. //

Un músico entra en un estudio después de haber integrado dos bandas conocidas. / Tiene experiencia, conoce los escenarios y sabe exactamente qué puede hacer con su instrumento. // Pero cuando la cinta empieza a girar, nada de eso toca por él. / La canción nueva tiene que funcionar. / La banda nueva tiene que encontrar su pulso. //

La reputación puede conseguir una entrevista. / No puede conseguir una buena toma. //

En los discos que llevan su nombre, Abrahams sigue explorando ese terreno. / Blues, rock, pasajes más contenidos, guitarras que vuelven a tomar la palabra. // No es una historia recta. / No hay una escalera que sube sin interrupciones. / Hay proyectos que se abren y se cierran. //

Y, mientras tanto, Lancaster sigue su propio camino. //

Es importante retenerlo porque en esta historia no todas las conexiones son evidentes. // Algunos músicos estuvieron en la misma banda. / Otros nunca coincidieron allí, pero quedaron unidos por las decisiones de quienes sí lo hicieron. //

Años después, Lancaster va a encontrarse con CLIVE BUNKER. / Y entonces una parte de aquella primera separación de 1968 va a volver a sonar en una sala distinta. //

No como una reunión. / Como una nueva banda. //


CUANDO EL NOMBRE YA NO ALCANZA

En la historia de MICK ABRAHAMS hay una paradoja. / Lo conocen por haberse ido de Jethro Tull. / Pero lo que hace después demuestra que su historia no cabe dentro de aquella salida. //

BLODWYN PIG tiene una identidad propia, y se escucha en cómo reparte el protagonismo. / La guitarra no necesita tapar los saxofones. / Los instrumentos de viento no llegan para hacer una imitación de la flauta de Anderson. // JACK LANCASTER tiene un lenguaje propio y lo usa para ensanchar las canciones. //

THE MODERN ALCHEMIST es una buena puerta para entrar a ese mundo. / La banda se permite una construcción instrumental más libre. / La idea de que Abrahams solamente quería tocar blues tradicional se queda corta cuando escuchamos todo lo que sucede alrededor de su guitarra. //

Ahí está la complejidad de la historia. / No se fue porque odiara experimentar. / Quería decidir desde qué música experimentar. //

Cuando Blodwyn Pig cambia y Abrahams continúa bajo su nombre, aparece otra prueba. / Una banda puede tener dos discos valiosos y aun así no conseguir mantenerse unida. // El estudio no resuelve los problemas de convivencia. / El escenario tampoco. / Lo que sobrevive es el trabajo que quedó grabado. //

La música no cuenta una victoria definitiva. / Cuenta una sucesión de intentos. // Y eso hace que la historia sea más humana. //


MÚSICA DEL CAPÍTULO 2 — THE MICK ABRAHAMS BAND
1. Greyhound Bus — Presenta el nuevo recorrido del guitarrista bajo su propio nombre.
2. Why Do You Do Me This Way — Recupera el filo y el pulso del blues-rock que lo identificaba.
3. Seasons — Permite escuchar otra faceta de su escritura y su manera de tocar.
4. You'll Never Get It From Me — Cierra el recorrido por su etapa posterior a Blodwyn Pig.

CAPÍTULO 3 — WILD TURKEY
EL BAJISTA QUE TUVO QUE VOLVER AL PRINCIPIO

Inglaterra. / 1970. //

Imaginá que desaparece el bajo de una canción. / La guitarra sigue. / La batería sigue. / La voz todavía está ahí. // Pero de pronto falta el piso. //

Eso es lo que hace un buen bajista: sostiene una música incluso cuando el público no está mirando sus manos. //

**GLENN CORNICK** lo había hecho desde los primeros tiempos de Jethro Tull. / Su instrumento no se limitaba a marcar las notas fundamentales. / Se movía entre la batería y la guitarra, encontraba huecos, proponía respuestas. //

Y ahora está afuera. //

La banda continúa. / Los discos siguen llegando. / El nombre Jethro Tull se vuelve cada vez más grande. // Pero Cornick tiene que resolver algo bastante menos espectacular: con quién va a tocar la semana siguiente, qué canciones van a ensayar, dónde van a conseguir actuaciones. //

No se queda inmóvil. / Forma **WILD TURKEY** (UÁILD TÉRKI). //

El nombre tiene algo de animal difícil de domesticar. / La música también busca un lugar distinto. / Sin la flauta de Anderson al frente y sin el peso de la identidad de Jethro Tull, las guitarras pueden avanzar con otra fuerza. //

En 1971 aparece **BATTLE HYMN**. //

No es la obra de un músico intentando borrar su pasado. / Es el trabajo de alguien que conoce el valor de una sección rítmica y quiere levantar otra banda alrededor de canciones nuevas. // El rock se endurece, pero todavía conserva la memoria del blues británico. //

Un año después llega **TURKEY**. //

Y acá conviene mirar el calendario. / Estamos en 1972. / El rock cambia de sonido a una velocidad feroz. / Los grupos que parecían destinados a durar una década a veces no sobreviven a dos discos. / Las formaciones se mueven. / Las oportunidades no alcanzan para todos. //

Wild Turkey atraviesa esos cambios sin convertirse en una banda de estadios. // Pero reducirla a lo que no consiguió sería perderse lo que sí dejó grabado. //

Escuchá el bajo de Cornick en este nuevo paisaje. / Ya no está dialogando con la flauta de Anderson. / Ahora sostiene canciones que tienen otras urgencias. / El músico es el mismo. / El lugar que ocupa es completamente distinto. //

La banda tendrá otras etapas y regresos. / Pero la escena decisiva está acá, al comienzo: un hombre sale de un grupo en ascenso y decide construir el siguiente desde cero. //

No vuelve a empezar porque haya olvidado cómo tocar. / Vuelve a empezar porque sabe hacerlo. //

LA BANDA QUE NO ESTABA EN EL CARTEL

Pensemos por un instante en GLENN CORNICK sobre un escenario de Jethro Tull. //

El público ve a Anderson al frente. / La flauta corta el aire. / La guitarra sostiene el riff. // Pero abajo hay un bajo que no se limita a seguir las órdenes. //

CORNICK pertenece a una generación de bajistas que empezó a darle al instrumento un papel más libre. / Ya no alcanza con marcar el pulso detrás de los demás. / El bajo puede llevar una melodía, anticipar un cambio, empujar al baterista hacia una sección nueva. //

Esa libertad se escucha en las primeras grabaciones de Jethro Tull. //

Por eso su salida en 1970 tiene un peso especial. / No se va un músico que pasaba inadvertido dentro del sonido. / Se va una de las piezas que habían ayudado a construirlo. //

Y lo que viene después no tiene ninguna garantía. //

En una banda que empieza de cero hay que volver a discutir cosas que parecían resueltas: quién escribe, quién canta, qué repertorio sirve, qué dirección conviene tomar. // La primera prueba no ocurre frente a miles de personas. / Ocurre cuando cuatro o cinco músicos intentan terminar una canción sin mirarse con dudas. //

WILD TURKEY nace de ese impulso. //

El nombre parece hecho para una banda que no quiere caminar en fila. / Y la música tampoco se acomoda fácilmente a una sola etiqueta. // Hay guitarras pesadas, melodías amplias, un pulso que todavía recuerda el blues y momentos donde el grupo se permite mirar hacia un rock más elaborado. //

En 1971 aparece BATTLE HYMN. //

El título podría traducirse como un himno de batalla. / Pero la batalla no es contra Jethro Tull. / Es contra algo mucho más difícil: la posibilidad de quedar reducido para siempre a «el exbajista de». //

La primera canción de una banda nueva tiene que convencer a un oyente que no conoce su historia. / No alcanza con el currículum. // Y Cornick parece entenderlo. / Su bajo sostiene una música con otro centro de gravedad, una voz distinta y una identidad que no necesita copiar a Anderson. //

BATTLE HYMN y BUTTERFLY permiten escuchar dos costados de esa búsqueda. / Uno empuja desde el título mismo hacia una afirmación de fuerza. / El otro deja espacio para una sensibilidad melódica que también forma parte de la banda. //

Después aparece TWELVE STREETS OF COBBLED BLACK. / Un título largo, casi una calle que no termina. // El grupo se mueve por arreglos que requieren atención y por un rock que todavía se permite desarrollar una idea antes de correr hacia el estribillo. //

DULWICH FOX devuelve el oído al primer álbum. / Es otra pieza de ese rompecabezas: la evidencia de que Wild Turkey no fue solamente una reacción inmediata a una salida, sino un proyecto con material propio. //

En 1972 llega TURKEY. //

La segunda oportunidad de un grupo no se parece a la primera. / Ya no existe la sorpresa de un debut. / Ahora hay que demostrar que aquello no fue un accidente. // Y alrededor todo se mueve. / Los gustos del público, las posibilidades de las compañías, los músicos disponibles. //

La primera etapa de Wild Turkey no se convierte en una historia de éxito masivo. / Pero sus discos permanecen. //

Y eso importa por una razón sencilla. / Durante años, cuando se habla de Jethro Tull, es fácil seguir los álbumes de la banda principal y olvidar lo que pasó con los que se fueron. // Al poner un disco de Wild Turkey, de pronto el mapa se agranda. //

La historia deja de tener un solo centro. //

Cornick ya no es el músico que falta en una foto. / Es el músico que aparece en otra. / Con otros compañeros, otras canciones y otro sonido. //


LO QUE EL BAJO RECUERDA

Hay una forma sencilla de escuchar el recorrido de GLENN CORNICK. / Poner una grabación temprana de Jethro Tull y después una de Wild Turkey. //

No hace falta que alguien explique qué cambió. / Lo dicen los instrumentos. //

En Jethro Tull, el bajo comparte un terreno donde la flauta puede aparecer en cualquier momento y la guitarra todavía conserva el idioma del blues. / En Wild Turkey, las guitarras ocupan otro espacio y la voz conduce canciones con un carácter diferente. //

El bajista tiene que adaptarse. / Y adaptarse no significa desaparecer. //

En una banda, el bajo también cuenta historias: a veces sostiene una nota hasta que el resto vuelve; a veces se mueve por debajo de una melodía; a veces parece anticipar el cambio de clima. // Cornick entiende esa función y la lleva consigo cuando cambia de compañeros. //

Por eso es importante no presentar Wild Turkey como una banda que solamente nació del resentimiento. / Su primer álbum contiene un repertorio propio, una búsqueda sonora y el trabajo de músicos que querían hacerse escuchar por sus canciones. //

Lo que ocurrió con Jethro Tull explica cómo empezó el camino. / No explica por sí solo todo lo que se escucha en BATTLE HYMN. //


MÚSICA DEL CAPÍTULO 3 — WILD TURKEY
1. Battle Hymn — La primera declaración de identidad del grupo de Cornick.
2. Butterfly — Muestra su costado melódico sin perder el pulso del rock.
3. Twelve Streets of Cobbled Black — Deja escuchar la ambición de sus arreglos.
4. Dulwich Fox — Devuelve al oyente al sonido del primer álbum, Battle Hymn.

CAPÍTULO 4 — AVIATOR
DOS CAMINOS EN LA MISMA HABITACIÓN

Inglaterra. / 1979. //

Pasaron once años desde aquel primer disco de Jethro Tull. //

El paisaje cambió. / El punk sacudió a la industria. / La nueva ola ocupa espacio en las radios. / Los músicos que habían pasado los años sesenta buscando nuevas formas para el blues ahora trabajan en un mundo que parece tener mucha menos paciencia. //

En ese escenario aparece una banda llamada **AVIATOR** (ÉIVIEITOR). //

Detrás de la batería está **CLIVE BUNKER**. / Sí, el mismo que había tocado en la primera formación de Jethro Tull y que había dejado el grupo después de Aqualung. //

Entre los instrumentos de viento está **JACK LANCASTER**. / El mismo que había acompañado a Mick Abrahams en Blodwyn Pig. //

Detenete un segundo en ese encuentro. //

Bunker y Lancaster no habían sido compañeros en Jethro Tull. / Lancaster nunca perteneció a aquella banda. // Pero ambos llegan a esta habitación por caminos que arrancan de la misma separación. //

Uno viene directamente de la primera formación. / El otro viene de la banda que fundó el guitarrista que se fue. //

Con ellos están **MICK ROGERS** (MIK RÓYERS), en guitarra, y **JOHN G. PERRY** (YON YI PÉRI), en bajo. //

No forman una banda para reconstruir el sonido de 1968. / La música de Aviator mira hacia otro lado: rock con arreglos amplios, cruces con el jazz, instrumentos que se responden sin pedir permiso. //

En 1979 publican **AVIATOR**. / En 1980 llega **TURBULENCE**, con cambios en la formación. //

La vida del grupo es breve. / Y tal vez por eso resulta tan reveladora. // No hay una larga carrera que tape los detalles. / Hay un encuentro preciso entre músicos que ya conocen los escenarios, los estudios y las despedidas. //

Ahora volvamos por un instante a 1968. //

La guitarra de Abrahams. / El bajo de Cornick. / La batería de Bunker. / La flauta de Anderson. //

Cuatro instrumentos que todavía intentaban descubrir si podían hablar el mismo idioma. //

De esa primera conversación salieron discos, cambios de formación y bandas nuevas. / Blodwyn Pig. / The Mick Abrahams Band. / Wild Turkey. / Aviator. //

Lo que parecía una sola banda separándose terminó siendo una red de músicos que siguieron encontrándose en otros escenarios. //

Y aquella puerta lateral, la que parecía conducir hacia afuera de la historia, terminó abriendo otra sala. //

EL ENCUENTRO QUE NADIE HABÍA PLANEADO EN 1968

Ahora estamos en 1979. //

Un músico que hubiera salido de un club londinense en 1968 y entrara de golpe en una sala de conciertos once años después encontraría un mundo distinto. //

Los amplificadores siguen ahí. / Las guitarras también. / Pero el rock ha cambiado de aspecto varias veces. // Pasó por la expansión del progresivo, por los grandes escenarios, por el golpe del punk y por nuevas formas de escribir canciones. //

No todos los músicos de la generación anterior encontraron un lugar cómodo en ese paisaje. //

AVIATOR aparece precisamente ahí. //

Su formación reúne experiencias que, vistas por separado, parecen pertenecer a capítulos distintos. // CLIVE BUNKER viene de la primera época de Jethro Tull. / JACK LANCASTER trae su historia con Blodwyn Pig. / MICK ROGERS aporta una guitarra marcada por otros recorridos del rock británico. / JOHN G. PERRY sostiene el bajo. //

Ninguno llega como un principiante. / Y sin embargo todos tienen que hacer lo que hace cualquier banda nueva: aprender a escucharse. //

Ese es el detalle que más me interesa de Aviator. //

No están intentando reconstruir el escenario donde Anderson levantaba la flauta en 1968. / Ni el sonido exacto de Blodwyn Pig. // Si hubieran querido vivir de esos nombres, podían haber convertido el proyecto en una mirada permanente hacia atrás. //

Pero las canciones buscan otro lugar. //

Hay espacio para los instrumentos de viento, para una guitarra que conversa con ellos, para una batería que no necesita golpear todo el tiempo con la misma fuerza. / El rock se cruza con arreglos amplios y con una sensibilidad distinta de la del blues original. //

El primer álbum se llama simplemente AVIATOR. / Sale en 1979. //

A veces un disco debut lleva un nombre extraño, pensado para llamar la atención. / Acá alcanza con el nombre de la banda. // Como si dijeran: esto es lo que somos ahora. / Escuchen antes de preguntar de dónde venimos. //

El segundo álbum, TURBULENCE, aparece en 1980 y el grupo atraviesa cambios. // El título parece apropiado para una banda que se mueve en una época de transición, aunque no haga falta convertirlo en una profecía. //

La trayectoria es breve. / No se transforma en una institución. / Y quizá por eso el encuentro entre Bunker y Lancaster conserva tanta fuerza. //

Pensalo de esta manera. //

En 1968, MICK ABRAHAMS se separa de Jethro Tull. / De ese camino nace BLODWYN PIG, donde toca JACK LANCASTER. //

En 1971, CLIVE BUNKER deja Jethro Tull. //

Son dos líneas que salen de momentos diferentes. / Una arranca con un guitarrista que quiere seguir tocando blues. / La otra con un baterista que cierra una etapa después de AQUALUNG. //

Durante años no hay ninguna razón para pensar que esas líneas deban tocarse. //

Y sin embargo se encuentran. //

En Aviator, Bunker y Lancaster no están representando el pasado. / Están tocando el presente de 1979. // Esa es la diferencia entre una banda de nostalgia y una banda nueva: el pasado explica cómo llegaron, pero no alcanza para tocar la próxima canción. //

Y ahora sí, volvamos al comienzo. //

Londres. / 1968. / Un bajo que se mueve, una batería que empuja, una guitarra de blues y una flauta que quiere llevar la música hacia otro lado. //

Si alguien hubiera detenido aquella actuación y preguntado qué iba a pasar con cada músico, nadie habría podido dibujar este mapa. //

Porque una banda no es solamente el grupo de personas que aparece en una tapa. / También es todo lo que esas personas hacen después de salir de ella. //

Y el rock, cuando se lo escucha así, deja de parecer una colección de nombres famosos. / Se convierte en una ciudad llena de puertas, pasillos y habitaciones donde la música nunca termina de apagarse. //


UNA CONVERSACIÓN QUE TARDA ONCE AÑOS

En 1968, CLIVE BUNKER y JACK LANCASTER no están sentados en la misma sala de ensayo. / Ni siquiera ocupan el mismo capítulo de esta historia. //

Bunker sostiene desde la batería a una banda que está aprendiendo a mezclar blues y nuevas formas de rock. / Lancaster todavía va a encontrar su lugar junto a Abrahams en Blodwyn Pig. //

Once años después, los dos aparecen en Aviator. //

Es tentador contar ese encuentro como si todo hubiera estado escrito desde el principio. / Pero el rock no funciona así. // Los músicos pasan por grupos, giras, grabaciones y cambios de época. / Algunos nombres vuelven a cruzarse. / Otros nunca vuelven a encontrarse. //

AVIATOR importa precisamente porque no era una conclusión obligatoria. //

Y hay otro detalle: el tiempo modifica lo que cada músico lleva a una banda. / Bunker no llega en 1979 siendo exactamente el baterista de 1968. / Lancaster tampoco es solamente el hombre que tocó con Abrahams diez años antes. // Cada uno trae experiencia acumulada, decisiones tomadas, escenarios recorridos. //

Cuando los escuchamos juntos, no escuchamos una foto antigua que se puso en movimiento. / Escuchamos músicos intentando construir algo en su presente. //

Esa es la imagen con la que quiero cerrar este recorrido: no una despedida congelada en 1968, sino una puerta que sigue abriéndose años después. //

1. Your Loving Is My Home — Presenta la faceta de canción del grupo.
2. Keep Your Heart Right — Permite escuchar la interacción de sus músicos.
3. Evil Eye — Muestra su búsqueda instrumental más intensa.
4. Way of the World — Cierra con el repertorio que figura en la selección musical cargada para el programa.

CIERRE GENERAL

Al principio escuchamos una puerta. / Una salida que, vista desde el escenario, parecía definitiva. //

Después encontramos otra guitarra. / Otro bajo. / Otra batería. / Y, muchos años más tarde, dos músicos que habían recorrido caminos distintos tocando en una misma banda. //

Quizá por eso conviene escuchar también a los que se fueron. / No para detenernos en la despedida, sino para descubrir todo lo que siguió sonando después. //

Soy Sebastián Sopelana. / Esto fue Ruidos Molestos. //

La historia llegó a su fin, el ROCK por suerte, no. //
