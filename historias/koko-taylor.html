KOKO TAYLOR

LA MUJER QUE NO PIDIÓ PERMISO

LA HISTORIA

HAY UNA IMAGEN QUE ME GUSTA MUCHO PARA EMPEZAR ESTA HISTORIA. //

UNA CASA DE CAMPO EN TENNESSEE. /

UNOS CHICOS QUE HAN TERMINADO, POR FIN, CON LAS TAREAS DEL DÍA. /

Y UNA PEQUEÑA BANDA QUE SE REÚNE DETRÁS DE LA CASA. //

NO TIENEN INSTRUMENTOS COMO LOS QUE VEMOS EN LOS ESCENARIOS. //

UNA GUITARRA ESTÁ HECHA CON ALAMBRES. /

OTRO INSTRUMENTO SE FABRICÓ CON UNA MAZORCA DE MAÍZ. //

Y HAY UNA CHICA QUE CANTA. //

SE LLAMA CORA WALTON. //

PERO MUCHOS AÑOS DESPUÉS EL MUNDO LA CONOCERÁ COMO KOKO TAYLOR. //

LOS CHICOS TOCAN A ESCONDIDAS PORQUE EN SU CASA HAY UNA DIFERENCIA MUY IMPORTANTE ENTRE LA MÚSICA QUE SE PUEDE CANTAR Y LA QUE NO. //

EL GOSPEL PERTENECE A LA IGLESIA. /

EL BLUES PERTENECE A OTRO MUNDO. //

UN MUNDO DE BARES, DE BAILES, DE NOCHES LARGAS Y DE HISTORIAS QUE MUCHOS PADRES PREFIEREN MANTENER LEJOS DE SUS HIJOS. //

PERO LOS CHICOS QUIEREN TOCAR BLUES. //

Y LO HACEN. //

A VECES, CUANDO HABLAMOS DE LA HISTORIA DE LA MÚSICA, NOS QUEDAMOS CON LAS GRANDES GRABACIONES. //

CON LOS DISCOS QUE VENDIERON MILES DE COPIAS. /

CON LOS PREMIOS. /

CON LAS FOTOGRAFÍAS DE LOS ARTISTAS FAMOSOS. //

PERO EN EL CASO DE KOKO TAYLOR, YO PREFIERO EMPEZAR POR AQUELLA GUITARRA HECHA CON ALAMBRE. //

PORQUE AHÍ HABÍA UNA NENA QUE TODAVÍA NO SABÍA QUE IBA A SER CANTANTE. //

SIMPLEMENTE SABÍA QUE LE GUSTABA CANTAR. //

CORA HABÍA NACIDO EN 1928, CERCA DE MEMPHIS. //

SU FAMILIA TRABAJABA EN EL CAMPO. //

NO ERA UNA VIDA CÓMODA. //

EN EL SUR DE ESTADOS UNIDOS, MUCHAS FAMILIAS AFROAMERICANAS CULTIVABAN TIERRAS QUE NO LES PERTENECÍAN. //

TRABAJABAN DURANTE MESES Y DESPUÉS TENÍAN QUE ENTREGAR UNA PARTE IMPORTANTE DE LO PRODUCIDO. //

EL SISTEMA LOS MANTENÍA ATADOS A UNA POBREZA DE LA QUE RESULTABA MUY DIFÍCIL SALIR. //

Y LOS HIJOS APRENDÍAN A TRABAJAR MUCHO ANTES DE TENER EDAD PARA ENTENDER POR QUÉ LA VIDA ERA TAN DIFÍCIL. //

KOKO CRECIÓ EN ESE AMBIENTE. //

PERO ADEMÁS TUVO QUE ENFRENTAR UNA PÉRDIDA ENORME. //

QUEDÓ HUÉRFANA SIENDO MUY JOVEN. //

Y ESO CAMBIÓ SU INFANCIA PARA SIEMPRE. //

NO QUIERO QUE IMAGINES QUE AQUELLA TRISTEZA LA CONVIRTIÓ AUTOMÁTICAMENTE EN UNA GRAN CANTANTE. //

LA VIDA NO FUNCIONA ASÍ. //

HAY PERSONAS QUE SUFREN MUCHO Y NUNCA TIENEN LA OPORTUNIDAD DE HACER LO QUE LES GUSTA. //

LO PARTICULAR DE KOKO FUE QUE, A PESAR DE LAS DIFICULTADES, NO DEJÓ DE ACERCARSE A LA MÚSICA. //

ESCUCHABA LA RADIO. //

Y LA RADIO ERA UNA VENTANA EXTRAORDINARIA. //

PORQUE PERMITÍA QUE UNA CHICA DE CAMPO ESCUCHARA VOCES QUE ESTABAN MUCHO MÁS ALLÁ DE SU VIDA COTIDIANA. //

MEMPHIS MINNIE. /

BESSIE SMITH. //

MUJERES QUE CANTABAN SIN DISCULPARSE POR LO QUE TENÍAN QUE DECIR. //

Y EN AQUELLOS DISCOS KOKO DESCUBRIÓ ALGO FUNDAMENTAL. //

QUE UNA MUJER PODÍA CONTAR SUS PROPIAS HISTORIAS. //

QUE PODÍA CANTAR SOBRE EL AMOR, LOS CELOS, EL ABANDONO Y EL DESEO. //

Y QUE PODÍA HACERLO CON UNA FUERZA CAPAZ DE IMPONERSE SOBRE UNA BANDA ENTERA. //

MUCHOS AÑOS DESPUÉS, ESA SERÍA UNA DE SUS GRANDES VIRTUDES. //

PERO TODAVÍA FALTABA MUCHO. //

EN 1952, KOKO Y SU MARIDO, ROBERT TAYLOR, DECIDIERON IRSE A CHICAGO. //

ERA PARTE DE UN MOVIMIENTO ENORME DE PERSONAS AFROAMERICANAS QUE ABANDONABAN EL SUR BUSCANDO TRABAJO Y MEJORES CONDICIONES DE VIDA EN LAS CIUDADES INDUSTRIALES DEL NORTE. //

CHICAGO PROMETÍA OPORTUNIDADES. //

PERO NO LAS REGALABA. //

ROBERT CONSIGUIÓ TRABAJO EN LA INDUSTRIA DE LA CARNE. //

KOKO LIMPIABA CASAS. //

Y DURANTE LA SEMANA LLEVABAN LA VIDA DE DOS PERSONAS QUE TRATABAN DE GANARSE EL SUSTENTO. //

PERO LOS FINES DE SEMANA HACÍAN ALGO QUE LES GUSTABA MUCHO. //

SALÍAN A ESCUCHAR BLUES. //

Y ACÁ APARECE UNA DE LAS CASUALIDADES MÁS LINDAS DE ESTA HISTORIA. //

LOS MÚSICOS QUE KOKO HABÍA ESCUCHADO POR RADIO ESTABAN TOCANDO EN LOS CLUBES DE CHICAGO. //

NO ERAN FIGURAS INALCANZABLES. //

SE PODÍA ENTRAR A UN LOCAL Y ESCUCHAR A MUDDY WATERS. /

A HOWLIN' WOLF. /

A BUDDY GUY. //

Y KOKO NO SE CONFORMABA CON ESCUCHAR. //

CUANDO TENÍA OPORTUNIDAD, CANTABA. //

ROBERT LA ALENTABA. //

SABÍA QUE SU MUJER TENÍA UNA VOZ EXTRAORDINARIA. //

Y POCO A POCO, LOS MÚSICOS DE LA CIUDAD EMPEZARON A PRESTARLE ATENCIÓN. //

NO ERA UNA VOZ DELICADA. //

NO ERA UNA CANTANTE QUE NECESITARA QUE LA BANDA BAJARA EL VOLUMEN PARA PODER ESCUCHARLA. //

ERA UNA VOZ ÁSPERA, PODEROSA, CON UNA PERSONALIDAD QUE NO SE CONFUNDÍA CON NINGUNA OTRA. //

EN 1962, WILLIE DIXON LA ESCUCHÓ. //

Y ENTENDIÓ QUE AHÍ HABÍA ALGO ESPECIAL. //

DIXON ERA UNO DE LOS GRANDES ARQUITECTOS DEL BLUES DE CHICAGO. //

COMPONÍA CANCIONES. /

TOCABA EL CONTRABAJO. /

PRODUCÍA GRABACIONES. //

Y TENÍA UNA CAPACIDAD EXTRAORDINARIA PARA DESCUBRIR QUÉ CANCIÓN PODÍA FUNCIONAR CON DETERMINADO ARTISTA. //

LA LLEVÓ A CHESS RECORDS. //

Y UNOS AÑOS DESPUÉS LLEGÓ LA GRABACIÓN QUE LE CAMBIÓ LA VIDA. //

WANG DANG DOODLE. //

LA CANCIÓN HABÍA SIDO COMPUESTA POR DIXON Y YA HABÍA SIDO GRABADA POR HOWLIN' WOLF. //

PERO KOKO HIZO ALGO DIFERENTE CON ELLA. //

LA CONVIRTIÓ EN UNA FIESTA. //

UNA FIESTA RUIDOSA, DESORDENADA, LLENA DE PERSONAJES Y CON UNA CANTANTE QUE PARECÍA ESTAR CONVOCANDO A TODO EL BARRIO. //

Y LA GENTE RESPONDIÓ. //

EL DISCO SE CONVIRTIÓ EN UN ÉXITO. //

DE PRONTO, LA MUJER QUE LIMPIABA CASAS ESTABA CANTANDO PARA PÚBLICOS CADA VEZ MÁS GRANDES. //

PERO EL ÉXITO NO SIGNIFICÓ QUE TODO FUERA SENCILLO. //

KOKO ERA UNA MUJER NEGRA EN UN NEGOCIO MUSICAL DOMINADO POR HOMBRES. //

Y EN MUCHAS OPORTUNIDADES TENÍA QUE DEMOSTRAR QUE PODÍA HACER EL MISMO TRABAJO QUE ELLOS. //

VIAJAR. /

SOSTENER UNA BANDA. /

SUBIRSE A UN ESCENARIO DESPUÉS DE HORAS DE RUTA. /

CANTAR CUANDO ESTABA CANSADA. //

Y VOLVER A EMPEZAR AL DÍA SIGUIENTE. //

ROBERT ESTABA A SU LADO. //

NO SOLAMENTE COMO MARIDO. //

TAMBIÉN COMO REPRESENTANTE Y COMPAÑERO DE TRABAJO. //

HABÍAN LLEGADO JUNTOS A CHICAGO. //

Y AHORA RECORRÍAN JUNTOS EL CAMINO QUE LOS LLEVABA A LOS ESCENARIOS. //

EN LOS AÑOS SETENTA, CUANDO CHESS YA NO TENÍA EL MISMO LUGAR EN EL NEGOCIO, KOKO ENCONTRÓ UNA NUEVA CASA DISCOGRÁFICA. //

ALLIGATOR RECORDS. //

EN 1975 PUBLICÓ I GOT WHAT IT TAKES. //

Y EL TÍTULO PARECÍA UNA DECLARACIÓN PERSONAL. //

TENGO LO QUE HACE FALTA. //

NO NECESITABA QUE ALGUIEN LE EXPLICARA CÓMO DEBÍA CANTAR BLUES. //

YA HABÍA PASADO AÑOS HACIÉNDOLO. //

EN 1985 RECIBIÓ UN GRAMMY POR EL DISCO BLUES EXPLOSION. //

Y SIGUIÓ VIAJANDO. //

PERO EN 1988, UN ACCIDENTE AUTOMOVILÍSTICO INTERRUMPIÓ BRUSCAMENTE SU CARRERA. //

SUFRIÓ HERIDAS IMPORTANTES. //

TUVO QUE ALEJARSE DEL ESCENARIO DURANTE MESES. //

Y PARA UNA PERSONA QUE HABÍA CONSTRUIDO SU VIDA ALREDEDOR DE LA MÚSICA, AQUELLA INACTIVIDAD FUE MUY DIFÍCIL. //

SE RECUPERÓ. //

VOLVIÓ A CANTAR. //

Y CUANDO PARECÍA QUE LA VIDA EMPEZABA A RECUPERAR SU RITMO, LLEGÓ UNA PÉRDIDA TODAVÍA MÁS PROFUNDA. //

MURIÓ ROBERT. //

EL HOMBRE QUE HABÍA ESTADO CON ELLA DESDE LOS AÑOS EN QUE NO TENÍAN NADA. //

EL COMPAÑERO DE AQUEL VIAJE A CHICAGO. //

EL QUE LA HABÍA ANIMADO A SUBIRSE A LOS ESCENARIOS. //

Y HAY ALGO MUY PARTICULAR EN ESA CLASE DE PÉRDIDA. //

PORQUE NO SE PIERDE SOLAMENTE A UNA PERSONA. //

TAMBIÉN SE PIERDE A ALGUIEN QUE RECUERDA TODA NUESTRA HISTORIA. //

ALGUIEN QUE ESTUVO PRESENTE ANTES DE LOS PREMIOS. //

ANTES DE LOS DISCOS. //

ANTES DE QUE LOS DEMÁS APRENDIERAN NUESTRO NOMBRE. //

KOKO SIGUIÓ CANTANDO. //

EN 1994 ABRIÓ SU PROPIO CLUB DE BLUES EN CHICAGO. //

LA MUJER QUE HABÍA ENTRADO A LOS CLUBES COMO ESPECTADORA AHORA TENÍA UNO CON SU NOMBRE. //

Y EN 2007, CASI A LOS 80 AÑOS, PUBLICÓ OLD SCHOOL. //

NO ERA UNA ARTISTA QUE ESTABA VIVIENDO SOLAMENTE DE SUS RECUERDOS. //

TODAVÍA TENÍA UNA VOZ. //

TODAVÍA TENÍA UNA BANDA. //

TODAVÍA TENÍA GANAS DE CANTAR. //

KOKO MURIÓ EL 3 DE JUNIO DE 2009. //

Y AUNQUE EL MUNDO LA CONOCIÓ COMO LA REINA DEL BLUES, YO PREFIERO TERMINAR ESTA HISTORIA CON AQUELLA CHICA QUE TOCABA A ESCONDIDAS DETRÁS DE UNA CASA. //

PORQUE AHÍ YA HABÍA ALGO QUE NADIE HABÍA PODIDO QUITARLE. //

LAS GANAS DE CANTAR. //
