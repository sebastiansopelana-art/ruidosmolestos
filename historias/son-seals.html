SON SEALS

EL BLUES QUE CRECIÓ DETRÁS DE UN BAR

LA HISTORIA

CUANDO SON SEALS ERA CHICO, NO NECESITABA SALIR DE SU CASA PARA ESCUCHAR BLUES. //

LA MÚSICA ESTABA AHÍ. //

A POCOS METROS. //

SU PADRE, JIM SEALS, TENÍA UN LOCAL EN OSCEOLA, ARKANSAS, LLAMADO THE DIPSY DOODLE. //

Y POR AQUEL LUGAR PASABAN MÚSICOS QUE MUCHOS AÑOS DESPUÉS SERÍAN RECORDADOS COMO GRANDES FIGURAS DEL BLUES. //

PERO PARA SON, EN AQUEL MOMENTO, ERAN SIMPLEMENTE LOS HOMBRES QUE TOCABAN EN EL BAR DE SU PADRE. //

LOS ESCUCHABA. //

LOS VEÍA PREPARAR LOS INSTRUMENTOS. //

LOS OBSERVABA DURANTE LAS PRESENTACIONES. //

Y CRECIÓ ENTENDIENDO QUE LA MÚSICA NO ERA SOLAMENTE LO QUE OCURRÍA CUANDO SE ENCENDÍAN LAS LUCES DEL ESCENARIO. //

TAMBIÉN ERA TRABAJO. //

ERA ENSAYAR. //

ERA VIAJAR. //

ERA CARGAR EQUIPOS. //

ERA VOLVER A CASA CANSADO. //

Y AL DÍA SIGUIENTE, EMPEZAR DE NUEVO. //

SU PADRE CONOCÍA BIEN ESE MUNDO. //

HABÍA TRABAJADO COMO MÚSICO. //

Y HABÍA PARTICIPADO EN ESPECTÁCULOS ITINERANTES. //

POR ESO, CUANDO SU HIJO EMPEZÓ A INTERESARSE POR LOS INSTRUMENTOS, NO LO TRATÓ COMO SI ESTUVIERA JUGANDO. //

LE ENSEÑÓ A TOCAR. //

PERO NO LE PERMITÍA HACER CUALQUIER COSA. //

SON QUERÍA RECORRER EL MÁSTIL DE LA GUITARRA. //

QUERÍA HACER SOLOS. //

QUERÍA TOCAR COMO LOS HOMBRES QUE VEÍA EN EL BAR. //

PERO SU PADRE LE EXIGÍA QUE APRENDIERA PRIMERO A SOSTENER EL RITMO. //

A VECES TENÍA QUE QUEDARSE MUCHO TIEMPO TOCANDO UN MISMO ACORDE. //

Y PARA UN CHICO IMPACIENTE, ESO PODÍA SER DESESPERANTE. //

PERO AQUELLA ENSEÑANZA TERMINÓ SIENDO FUNDAMENTAL. //

PORQUE SON APRENDIÓ A ESCUCHAR LA MÚSICA DESDE ADENTRO. //

Y TAMBIÉN APRENDIÓ A TOCAR LA BATERÍA. //

DE HECHO, DURANTE UNA PARTE IMPORTANTE DE SU JUVENTUD TRABAJÓ COMO BATERISTA. //

TOCÓ CON MÚSICOS COMO ALBERT KING. //

Y ESA EXPERIENCIA DEJÓ UNA MARCA EN SU MANERA DE TOCAR LA GUITARRA. //

PORQUE CUANDO UNO ESCUCHA A SON SEALS, LO PRIMERO QUE LLAMA LA ATENCIÓN ES SU FUERZA. //

PERO SI ESCUCHA CON ATENCIÓN, DESCUBRE QUE DETRÁS DE AQUELLA FUERZA HAY UN SENTIDO RÍTMICO MUY PROFUNDO. //

SON HABÍA APRENDIDO A TOCAR PARA UNA BANDA. //

NO SOLAMENTE PARA LUCIRSE. //

EN 1971 SE INSTALÓ EN CHICAGO. //

Y COMENZÓ A TRABAJAR EN LOS CLUBES DE LA CIUDAD. //

PERO TENÍA UNA IDEA MUY CLARA. //

NO QUERÍA PASARSE LA VIDA REPITIENDO LAS CANCIONES DE OTROS. //

QUERÍA ESCRIBIR. //

QUERÍA GRABAR. //

QUERÍA TENER SU PROPIA IDENTIDAD. //

Y EN 1973, BRUCE IGLAUER, EL FUNDADOR DE ALLIGATOR RECORDS, LE DIO LA OPORTUNIDAD DE GRABAR UN DISCO. //

SE LLAMÓ THE SON SEALS BLUES BAND. //

ERA UN ÁLBUM DIRECTO. //

SIN DEMASIADOS ADORNOS. //

CON UNA GUITARRA ÁSPERA Y UNA VOZ QUE NO PARECÍA INTERESADA EN RESULTAR AGRADABLE. //

SON NO QUERÍA SUAVIZAR SU MÚSICA. //

QUERÍA QUE SONARA COMO ÉL. //

Y EN AQUEL DISCO HABÍA CANCIONES COMO YOUR LOVE IS LIKE A CANCER Y HOT SAUCE. //

DOS TÍTULOS QUE YA NOS DICEN ALGO SOBRE SU PERSONALIDAD. //

NO ERA UN HOMBRE QUE UTILIZARA DEMASIADAS VUELTAS PARA DECIR LO QUE PENSABA. //

PERO DETRÁS DE AQUELLA DUREZA TAMBIÉN HABÍA UN MÚSICO QUE CONOCÍA MUY BIEN SU OFICIO. //

EN 1976 PUBLICÓ MIDNIGHT SON. //

UN DISCO CON UN SONIDO MÁS ELABORADO. //

CON VIENTOS. //

CON ARREGLOS QUE LO ACERCABAN AL FUNK Y AL SOUL. //

Y ESO DEMOSTRABA QUE SON NO QUERÍA QUEDARSE ENCERRADO EN LA FÓRMULA DE SU PRIMER ÁLBUM. //

QUERÍA SEGUIR CRECIENDO. //

PERO SU CARRERA NO FUE UNA SUCESIÓN ININTERRUMPIDA DE BUENAS NOTICIAS. //

HUBO CONFLICTOS PROFESIONALES. //

CAMBIOS DE BANDA. //

MOMENTOS EN LOS QUE SU RELACIÓN CON LA INDUSTRIA DISCOGRÁFICA NO FUE SENCILLA. //

Y DESPUÉS LLEGARON LOS PROBLEMAS PERSONALES Y DE SALUD. //

EN 1995 SUFRIÓ UN ACCIDENTE AUTOMOVILÍSTICO QUE LE PRODUJO UNA LESIÓN IMPORTANTE EN LA MANO IZQUIERDA. //

PARA UN GUITARRISTA, ESO ES UN PROBLEMA ENORME. //

PORQUE ESA MANO ES LA QUE TRABAJA SOBRE EL MÁSTIL. //

LA QUE FORMA LOS ACORDES. //

LA QUE ESTIRA LAS CUERDAS. //

LA QUE PERMITE QUE UNA NOTA SE TRANSFORME EN UNA FRASE. //

SON TUVO QUE RECUPERARSE. //

Y VOLVIÓ A TOCAR. //

PERO EN 1997 RECIBIÓ UN DISPARO DURANTE UN EPISODIO DE VIOLENCIA DOMÉSTICA. //

SUFRIÓ HERIDAS EN LA ZONA DE LA CARA Y EL CUELLO. //

Y OTRA VEZ TUVO QUE ENFRENTAR UNA RECUPERACIÓN DIFÍCIL. //

COMO SI ESO NO FUERA SUFICIENTE, LA DIABETES QUE PADECÍA LE PROVOCÓ COMPLICACIONES GRAVES. //

EN 1999 TUVIERON QUE AMPUTARLE PARTE DE LA PIERNA IZQUIERDA. //

Y ACÁ QUIERO DETENERME UN MOMENTO. //

PORQUE A VECES CONTAMOS ESTAS COSAS COMO SI FUERAN SOLAMENTE UNA LISTA DE DESGRACIAS. //

UN ACCIDENTE. //

UN DISPARO. //

UNA AMPUTACIÓN. //

PERO DETRÁS DE CADA UNA DE ESAS PALABRAS HABÍA MESES DE RECUPERACIÓN. //

DOLOR. //

CAMBIOS EN LA VIDA COTIDIANA. //

Y UN HOMBRE QUE TODAVÍA QUERÍA SUBIRSE A UN ESCENARIO. //

SON NO DEJÓ DE HACER MÚSICA. //

EN 2000 PUBLICÓ LETTIN' GO. //

Y EL DISCO TENÍA ALGO PARTICULAR. //

NO ERA SOLAMENTE EL REGRESO DE UN MÚSICO DESPUÉS DE VARIOS PROBLEMAS DE SALUD. //

ERA UN TRABAJO QUE MOSTRABA QUE TODAVÍA TENÍA GANAS DE PROBAR COSAS NUEVAS. //

EN AQUEL ÁLBUM PARTICIPÓ TREY ANASTASIO, EL GUITARRISTA DE PHISH. //

Y ACÁ APARECE UNA DE LAS PARTES MÁS LINDAS DE ESTA HISTORIA. //

PHISH ERA UNA BANDA DE ROCK DE OTRA GENERACIÓN. //

TENÍA SU PROPIO PÚBLICO. //

SUS PROPIAS COSTUMBRES. //

Y UNA MANERA DE TRABAJAR MUY DIFERENTE DE LA DE LOS BLUESMEN TRADICIONALES. //

PERO HABÍA UNA CANCIÓN DE SON SEALS QUE LES GUSTABA ESPECIALMENTE. //

FUNKY BITCH. //

LA INCORPORARON A SU REPERTORIO. //

Y CON EL TIEMPO SE CONVIRTIÓ EN UNA CANCIÓN CONOCIDA POR SUS SEGUIDORES. //

ASÍ QUE UNA COMPOSICIÓN NACIDA EN EL MUNDO DEL BLUES DE CHICAGO TERMINÓ SONANDO EN CONCIERTOS DE ROCK ANTE UNA GENERACIÓN DISTINTA. //

Y SON LLEGÓ A COMPARTIR ESCENARIO CON ELLOS. //

ES UNA HISTORIA QUE ME GUSTA PORQUE DEMUESTRA QUE LA MÚSICA PUEDE VIAJAR MUCHO MÁS LEJOS DE LO QUE IMAGINA QUIEN LA COMPONE. //

SON NO HABÍA ESCRITO AQUELLA CANCIÓN PENSANDO EN PHISH. //

LA HABÍA ESCRITO COMO PARTE DE SU PROPIO REPERTORIO. //

PERO AÑOS DESPUÉS OTROS MÚSICOS LA ENCONTRARON. //

LA HICIERON SUYA. //

Y LA LLEVARON A OTRO PÚBLICO. //

SON MURIÓ EL 20 DE DICIEMBRE DE 2004. //

TENÍA 62 AÑOS. //

Y AUNQUE SUS ÚLTIMOS AÑOS ESTUVIERON MARCADOS POR PROBLEMAS DE SALUD, SU MÚSICA SIGUIÓ CIRCULANDO. //

PERO YO NO QUIERO TERMINAR ESTA HISTORIA CON LA IMAGEN DE UN HOMBRE ENFERMO. //

QUIERO VOLVER AL DIPSY DOODLE. //

AL BAR DE SU PADRE. //

AL CHICO QUE ESCUCHABA A LOS MÚSICOS DESDE MUY PEQUEÑO. //

AL MUCHACHO QUE QUERÍA HACER SOLOS Y AL PADRE QUE LE DECÍA QUE PRIMERO TENÍA QUE APRENDER A TOCAR UN ACORDE. //

PORQUE HAY ALGO DE AQUELLA ENSEÑANZA QUE SE ESCUCHA DURANTE TODA SU CARRERA. //

SON SEALS PODÍA TOCAR CON UNA FUERZA EXTRAORDINARIA. //

PERO NUNCA DEJÓ DE SER UN MÚSICO QUE ENTENDÍA EL RITMO. //

Y ESO LO HABÍA APRENDIDO EN SU CASA. //

MUCHO ANTES DE CHICAGO. //

MUCHO ANTES DE ALLIGATOR RECORDS. //

MUCHO ANTES DE QUE EL MUNDO APRENDIERA SU NOMBRE. //
