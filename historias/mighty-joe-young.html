MIGHTY JOE YOUNG

EL HOMBRE QUE SE QUEDÓ SIN GUITARRA

LA HISTORIA

HAY UNA COSA QUE ME RESULTA DIFÍCIL DE IMAGINAR. //

UN GUITARRISTA QUE LLEVA CASI TODA SU VIDA TOCANDO. /

QUE CONOCE EL INSTRUMENTO TAN BIEN COMO SUS PROPIAS MANOS. /

QUE NO NECESITA MIRAR EL MÁSTIL PARA SABER DÓNDE ESTÁ UNA NOTA. //

Y QUE UN DÍA DESCUBRE QUE SUS DEDOS YA NO RESPONDEN. //

LA GUITARRA SIGUE AHÍ. //

LAS CUERDAS SON LAS MISMAS. //

EL AMPLIFICADOR ENCIENDE. //

PERO LAS MANOS YA NO HACEN LO QUE HACÍAN ANTES. //

ESTA ES UNA PARTE DE LA HISTORIA DE MIGHTY JOE YOUNG. //

PERO ANTES DE LLEGAR A ESE MOMENTO, QUIERO CONTARTE QUIÉN ERA EL HOMBRE QUE HABÍA DETRÁS DE LA GUITARRA. //

JOE HABÍA NACIDO EN 1927, EN SHREVEPORT, LUISIANA. //

CRECIÓ EN MILWAUKEE. //

Y ANTES DE CONSOLIDARSE COMO MÚSICO, PASÓ POR UNA ACTIVIDAD QUE NO PARECE TENER MUCHO QUE VER CON EL BLUES. //

EL BOXEO. //

FUE BOXEADOR AFICIONADO. //

Y SU ASPECTO FÍSICO AYUDÓ A QUE TERMINARA RECIBIENDO UN APODO MUY PARTICULAR. //

MIGHTY JOE YOUNG. //

EL NOMBRE COINCIDÍA CON EL DE UNA PELÍCULA DE 1949 SOBRE UN GORILA GIGANTESCO. //

PERO DETRÁS DE AQUEL APODO HABÍA UN GUITARRISTA MUCHO MÁS SUTIL DE LO QUE SU ASPECTO PODÍA HACER PENSAR. //

PORQUE JOE TENÍA UNA CUALIDAD QUE NO TODOS LOS MÚSICOS DESARROLLAN. //

SABÍA ACOMPAÑAR. //

Y ESO PARECE SENCILLO HASTA QUE UNO ESCUCHA A ALGUIEN QUE NO SABE HACERLO. //

HAY GUITARRISTAS QUE TOCAN TODO EL TIEMPO. //

QUE NO DEJAN UN SOLO ESPACIO VACÍO. //

QUE PARECEN ESTAR PELEANDO CON EL CANTANTE PARA VER QUIÉN SE ESCUCHA MÁS. //

MIGHTY JOE ERA DIFERENTE. //

SABÍA QUE UNA BUENA FRASE DE GUITARRA PODÍA DURAR SOLAMENTE DOS SEGUNDOS. //

Y QUE DESPUÉS HABÍA QUE DEJAR QUE LA CANCIÓN RESPIRARA. //

EN CHICAGO, ESA CAPACIDAD LE ABRIÓ MUCHAS PUERTAS. //

TOCÓ CON JIMMY ROGERS. //

CON BILLY BOY ARNOLD. //

CON OTIS RUSH. //

Y SE MOVIÓ EN UNA ESCENA DONDE EL BLUES ESTABA CAMBIANDO. //

PORQUE CHICAGO NO ERA SOLAMENTE UNA CIUDAD DE BLUES TRADICIONAL. //

TAMBIÉN ERA UNA CIUDAD DE SOUL. //

DE MÚSICA BAILABLE. //

DE ARREGLOS CON VIENTOS. //

DE CANTANTES QUE ESTABAN BUSCANDO NUEVAS MANERAS DE CONTAR HISTORIAS DE AMOR Y DESENGAÑO. //

Y JOE ESCUCHABA TODO ESO. //

NO QUERÍA QUEDARSE ENCERRADO EN UNA SOLA FÓRMULA. //

LE GUSTABA EL BLUES. //

PERO TAMBIÉN LE GUSTABA EL SOUL. //

Y CUANDO EMPEZÓ A GRABAR BAJO SU PROPIO NOMBRE, ESA MEZCLA SE CONVIRTIÓ EN SU IDENTIDAD. //

EN 1971 PUBLICÓ BLUES WITH A TOUCH OF SOUL. //

BLUES CON UN TOQUE DE SOUL. //

EL TÍTULO NO PODÍA SER MÁS PRECISO. //

ERA LA MÚSICA DE UN HOMBRE QUE HABÍA APRENDIDO EL OFICIO ACOMPAÑANDO A LOS GRANDES BLUESMEN, PERO QUE TAMBIÉN ENTENDÍA LO QUE ESTABA PASANDO EN LOS CLUBES DE SU CIUDAD. //

EN EL DISCO PARTICIPARON MÚSICOS COMO JIMMY DAWKINS Y JOHNNY BIG MOOSE WALKER. //

Y ESO NOS DICE ALGO IMPORTANTE. //

JOE ERA RESPETADO POR SUS COMPAÑEROS. //

NO ERA SOLAMENTE UN GUITARRISTA QUE CONSEGUÍA TRABAJO PORQUE ESTABA DISPONIBLE. //

ERA ALGUIEN CON QUIEN OTROS MÚSICOS QUERÍAN TOCAR. //

PERO HAY OTRA PARTE DE SU CARRERA QUE ME GUSTA ESPECIALMENTE. //

TIENE QUE VER CON UN CLUB LLAMADO WISE FOOLS PUB. //

DURANTE AÑOS, JOE FUE UNO DE LOS MÚSICOS HABITUALES DEL LUGAR. //

Y DURANTE DOCE AÑOS CONSECUTIVOS TOCÓ ALLÍ EN LA NOCHE DE AÑO NUEVO. //

DOCE AÑOS. //

PENSÁ LO QUE SIGNIFICA ESO. //

NOSOTROS SOLEMOS MEDIR EL ÉXITO DE UN MÚSICO POR LA CANTIDAD DE DISCOS QUE VENDE. //

POR LOS ESTADIOS QUE LLENA. //

POR LOS PREMIOS QUE RECIBE. //

PERO HAY OTRA CLASE DE ÉXITO. //

EL DE UN MÚSICO QUE SE CONVIERTE EN PARTE DE LA VIDA DE UNA COMUNIDAD. //

EL HOMBRE AL QUE LA GENTE QUIERE ESCUCHAR CUANDO TERMINA EL AÑO. //

CUANDO BRINDA. //

CUANDO SE REÚNE CON SUS AMIGOS. //

CUANDO QUIERE PASAR UNA BUENA NOCHE. //

MIGHTY JOE ERA ESE MÚSICO. //

Y EN AQUEL CLUB SU BANDA ENCONTRÓ UN LUGAR DONDE PODÍA DESARROLLAR SU SONIDO SIN ESTAR PENDIENTE DE LAS MODAS. //

TOCABA BLUES. //

TOCABA SOUL. //

Y HACÍA QUE LA GENTE SE QUEDARA. //

EN 1981, SU MÚSICA TAMBIÉN LLEGÓ AL CINE. //

PARTICIPÓ EN LA BANDA SONORA DE THIEF, UNA PELÍCULA DIRIGIDA POR MICHAEL MANN. //

ERA UNA HISTORIA CRIMINAL AMBIENTADA EN CHICAGO. //

Y LA MÚSICA DE JOE FORMABA PARTE DE AQUEL MUNDO NOCTURNO. //

UNA VEZ MÁS, NO NECESITABA CONVERTIRSE EN UNA ESTRELLA PARA DEJAR SU MARCA. //

SU GUITARRA PODÍA APARECER EN UN CLUB. //

EN UN DISCO. //

O EN UNA PELÍCULA. //

PERO EN 1986, CUANDO ESTABA TRABAJANDO EN NUEVAS GRABACIONES, LLEGÓ EL PROBLEMA QUE CAMBIARÍA SU VIDA. //

TUVO QUE SOMETERSE A UNA OPERACIÓN EN EL CUELLO. //

Y DESPUÉS DE AQUELLA INTERVENCIÓN SUFRIÓ ALTERACIONES EN LA SENSIBILIDAD Y EL MOVIMIENTO DE LAS MANOS. //

PARA UN GUITARRISTA, ESO ERA DEVASTADOR. //

JOE NO HABÍA PERDIDO EL INTERÉS POR LA MÚSICA. //

NO HABÍA DECIDIDO DEJAR DE TOCAR. //

SIMPLEMENTE, SU CUERPO YA NO RESPONDÍA COMO ANTES. //

Y AHÍ APARECE UNA DE LAS PARTES MÁS TRISTES DE ESTA HISTORIA. //

PORQUE HAY PERSONAS QUE SE RETIRAN DE UNA ACTIVIDAD CUANDO SIENTEN QUE YA CUMPLIERON SU CICLO. //

PERO JOE NO QUERÍA RETIRARSE. //

QUERÍA VOLVER. //

QUERÍA RECUPERAR SU GUITARRA. //

MIENTRAS TANTO, SIGUIÓ TRABAJANDO CON LA MÚSICA DE OTRAS MANERAS. //

CANTABA. //

PARTICIPABA EN GRABACIONES. //

Y TRATABA DE COMPLETAR EL DISCO QUE HABÍA COMENZADO. //

EL PROYECTO TARDÓ AÑOS EN TERMINARSE. //

PERO FINALMENTE, EN 1997, APARECIÓ MIGHTY MAN. //

EL TÍTULO VOLVÍA A JUGAR CON AQUEL APODO DE JUVENTUD. //

PERO AHORA TENÍA OTRO SIGNIFICADO. //

PORQUE EL HOMBRE QUE HABÍA SIDO BOXEADOR Y QUE HABÍA PASADO DÉCADAS CON UNA GUITARRA ENTRE LAS MANOS, HABÍA TENIDO QUE ENFRENTAR UNA PELEA MUCHO MÁS DIFÍCIL. //

LA DE SEGUIR SIENDO MÚSICO SIN PODER TOCAR COMO ANTES. //

EN AQUEL DISCO APARECIERON MÚSICOS QUE LO ACOMPAÑARON Y AYUDARON A COMPLETAR EL TRABAJO. //

Y ESO TAMBIÉN DICE ALGO SOBRE SU VIDA. //

PORQUE DESPUÉS DE TANTOS AÑOS ACOMPAÑANDO A OTROS, AHORA ERAN OTROS LOS QUE LO ACOMPAÑABAN A ÉL. //

JOE TODAVÍA TENÍA UNA ESPERANZA. //

VOLVER A RECUPERAR LA SENSIBILIDAD EN LOS DEDOS. //

EN 1998 SE SOMETIÓ A OTRA OPERACIÓN. //

PERO SU SALUD SE COMPLICÓ. //

Y EL 25 DE MARZO DE 1999 MURIÓ. //

TENÍA 71 AÑOS. //

HAY ALGO QUE ME QUEDA DANDO VUELTAS CUANDO PIENSO EN SU HISTORIA. //

DURANTE GRAN PARTE DE SU VIDA, MIGHTY JOE HABÍA SIDO EL HOMBRE QUE ESTABA AL LADO DE OTRO MÚSICO. //

EL GUITARRISTA QUE SOSTENÍA LA CANCIÓN. //

EL QUE ENTRABA EN EL MOMENTO JUSTO. //

EL QUE SABÍA CUÁNDO CALLARSE. //

Y CUANDO PERDIÓ LA POSIBILIDAD DE TOCAR, DESCUBRIÓ CUÁNTO SIGNIFICABA PARA ÉL AQUEL INSTRUMENTO. //

NO ERA UN OBJETO. //

ERA SU MANERA DE ESTAR EN EL MUNDO. //

Y AUNQUE SU NOMBRE NO SEA TAN CONOCIDO COMO EL DE OTROS GUITARRISTAS DE CHICAGO, HAY MUCHÍSIMA MÚSICA QUE SUENA COMO SUENA PORQUE ÉL ESTUVO AHÍ. //

SELECCIÓN MUSICAL — MIGHTY JOE YOUNG

PRIMER TEMA: WHY BABY?

VAMOS A ESCUCHAR UNA DE LAS CANCIONES QUE NOS PERMITEN RECONOCER SU MANERA DE CANTAR Y TOCAR. / LA ELEGIMOS PORQUE NOS ACERCA AL MÚSICO QUE EMPEZABA A BUSCAR SU PROPIO LUGAR DESPUÉS DE AÑOS DE ACOMPAÑAR A OTROS. //

SEGUNDO TEMA: SOMEBODY LOAN ME A DIME.

ESTA COMPOSICIÓN DE FENTON ROBINSON FORMÓ PARTE DEL REPERTORIO QUE JOE GRABÓ PARA DELMARK. / LA ELEGIMOS PORQUE PERMITE ESCUCHARLO DESARROLLAR UN BLUES EXTENSO, CON ESPACIO PARA LA GUITARRA Y PARA LA EXPRESIÓN DE TODA LA BANDA. //

TERCER TEMA: EVERY MAN NEEDS A WOMAN.

ACÁ APARECE EL MIGHTY JOE MÁS CERCANO AL SOUL. / UNA CANCIÓN QUE NOS AYUDA A ENTENDER POR QUÉ SU MÚSICA NO SE LIMITABA A REPETIR EL BLUES TRADICIONAL DE CHICAGO. // JOE QUERÍA QUE SUS CANCIONES TUVIERAN OTRO COLOR. //

CUARTO TEMA: TURNING POINT.

Y PARA TERMINAR, UNA GRABACIÓN DE MIGHTY MAN. / LA ELEGIMOS PORQUE PERTENECE A ESE DISCO QUE TARDÓ TANTOS AÑOS EN COMPLETAR. // ES LA OPORTUNIDAD DE ESCUCHAR A UN HOMBRE QUE, AUNQUE HABÍA PERDIDO GRAN PARTE DE SU CAPACIDAD PARA TOCAR LA GUITARRA, TODAVÍA TENÍA MÚSICA PARA COMPARTIR. //
