CAREY BELL

EL SAXOFÓN QUE NUNCA LLEGÓ

LA HISTORIA

EN LA VIDA DE ALGUNOS MÚSICOS HAY UN INSTRUMENTO QUE LO CAMBIA TODO. //

PERO EN LA DE CAREY BELL, EL INSTRUMENTO QUE QUERÍA NO FUE EL QUE TERMINÓ TOCANDO. //

CAREY HABÍA NACIDO EN 1936, EN MACON, MISSISSIPPI. //

Y CUANDO ERA CHICO LE GUSTABA EL SAXOFÓN. //

NO LA ARMÓNICA. //

EL SAXOFÓN. //

LE GUSTABA ESE SONIDO GRANDE, REDONDO, CAPAZ DE DESTACARSE SOBRE UNA BANDA. //

PERO EN SU CASA NO HABÍA DINERO PARA COMPRAR UNO. //

ENTONCES TERMINÓ CON UNA ARMÓNICA. //

UN INSTRUMENTO PEQUEÑO. //

BARATO. //

QUE PODÍA GUARDARSE EN EL BOLSILLO. //

Y QUE, EN MANOS DE LA PERSONA INDICADA, PODÍA PRODUCIR UNA CANTIDAD EXTRAORDINARIA DE SONIDOS. //

CAREY EMPEZÓ A ESCUCHAR A LOS GRANDES ARMONICISTAS. //

A LITTLE WALTER. //

A BIG WALTER HORTON. //

Y TRATABA DE DESCUBRIR CÓMO HACÍAN PARA SACAR AQUELLAS NOTAS. //

PERO HABÍA UN PROBLEMA. //

ESCUCHAR UN DISCO NO ES LO MISMO QUE TENER AL MÚSICO DELANTE. //

UNO PUEDE REPETIR UNA GRABACIÓN CIEN VECES Y SEGUIR SIN ENTENDER CÓMO SE CONSIGUE DETERMINADO SONIDO. //

CAREY QUERÍA APRENDER. //

Y EN 1956 TUVO LA OPORTUNIDAD DE IR A CHICAGO CON EL PIANISTA LOVIE LEE. //

ERA MUY JOVEN. //

PERO YA HABÍA TOCADO EN CONJUNTOS LOCALES. //

YA SABÍA LO QUE SIGNIFICABA SUBIRSE A UN ESCENARIO. //

Y AHORA ESTABA EN LA CIUDAD DONDE VIVÍAN SUS ÍDOLOS. //

UNA DE SUS PRIMERAS VISITAS FUE A UN CLUB LLAMADO ZANZIBAR. //

ALLÍ TOCABA LITTLE WALTER. //

PENSÁ EN ESA SITUACIÓN. //

UN MUCHACHO QUE HA PASADO AÑOS ESCUCHANDO A UN MÚSICO EN DISCOS. //

QUE HA TRATADO DE COPIAR SUS FRASES. //

QUE SE HA PREGUNTADO CÓMO CONSIGUE ESE SONIDO. //

Y QUE DE PRONTO ESTÁ DELANTE DE ÉL. //

LITTLE WALTER ERA UNA FIGURA FUNDAMENTAL. //

HABÍA TRANSFORMADO LA ARMÓNICA ELÉCTRICA. //

HABÍA APRENDIDO A UTILIZAR EL MICRÓFONO Y EL AMPLIFICADOR PARA CONSEGUIR UN SONIDO MÁS PODEROSO. //

Y HABÍA DEMOSTRADO QUE UNA ARMÓNICA PODÍA TENER LA MISMA FUERZA QUE UNA GUITARRA. //

CAREY LO ESCUCHÓ. //

LO CONOCIÓ. //

Y APRENDIÓ DE ÉL. //

PERO TODAVÍA TENÍA OTRO ENCUENTRO POR DELANTE. //

BIG WALTER HORTON. //

BIG WALTER TENÍA UNA MANERA MUY PARTICULAR DE TOCAR. //

SU SONIDO ERA PROFUNDO. //

PODÍA SOSTENER UNA NOTA Y HACER QUE PARECIERA MUCHO MÁS GRANDE DE LO QUE ERA. //

NO NECESITABA LLENAR TODOS LOS ESPACIOS. //

A VECES LE ALCANZABA CON UNA FRASE PARA CAMBIAR EL CLIMA DE UNA CANCIÓN. //

CAREY QUEDÓ FASCINADO. //

EMPEZÓ A SEGUIRLO. //

A ESCUCHARLO. //

Y CON EL TIEMPO SE CONVIRTIERON EN AMIGOS. //

PERO APRENDER A TOCAR BIEN NO GARANTIZABA CONSEGUIR TRABAJO. //

EN CHICAGO, LA ESCENA MUSICAL ESTABA CAMBIANDO. //

LOS GUITARRISTAS ELÉCTRICOS TENÍAN CADA VEZ MÁS PROTAGONISMO. //

Y NO SIEMPRE HABÍA LUGAR PARA OTRO ARMONICISTA. //

CAREY TENÍA QUE GANARSE LA VIDA. //

ENTONCES TOMÓ UNA DECISIÓN PRÁCTICA. //

APRENDIÓ A TOCAR EL BAJO. //

HOUND DOG TAYLOR LO AYUDÓ A DESARROLLAR ESE INSTRUMENTO. //

Y CAREY EMPEZÓ A CONSEGUIR TRABAJO COMO BAJISTA. //

INCLUSO TOCÓ EL BAJO EN LA BANDA DE BIG WALTER HORTON. //

ES UNA SITUACIÓN CURIOSA. //

EL JOVEN QUE HABÍA LLEGADO A CHICAGO PARA APRENDER ARMÓNICA DE UNO DE SUS GRANDES MAESTROS TERMINABA ACOMPAÑÁNDOLO CON OTRO INSTRUMENTO. //

PERO NO ERA UNA DERROTA. //

ERA UNA MANERA DE SEGUIR DENTRO DE LA MÚSICA. //

Y ADEMÁS LE PERMITÍA APRENDER ALGO QUE DESPUÉS SERÍA FUNDAMENTAL. //

ESCUCHAR A LOS DEMÁS. //

CUANDO UNO TOCA EL BAJO, NO PUEDE PENSAR SOLAMENTE EN SUS PROPIAS NOTAS. //

TIENE QUE ESCUCHAR AL BATERISTA. //

AL CANTANTE. //

AL PIANISTA. //

A LA GUITARRA. //

Y CAREY APRENDIÓ A ENTENDER UNA BANDA DESDE ADENTRO. //

EN 1969 LLEGÓ UNA OPORTUNIDAD IMPORTANTE. //

GRABÓ CAREY BELL'S BLUES HARP PARA DELMARK RECORDS. //

POR FIN PODÍA MOSTRAR SU TRABAJO COMO ARMONICISTA PRINCIPAL. //

Y EN AQUELLAS SESIONES PARTICIPARON MÚSICOS DE GRAN NIVEL, COMO PINETOP PERKINS, JIMMY DAWKINS Y EDDIE TAYLOR. //

EL DISCO INCLUÍA VERSIONES DE CANCIONES ASOCIADAS A LITTLE WALTER. //

Y ESO TENÍA UN SIGNIFICADO ESPECIAL. //

PORQUE EL JOVEN QUE HABÍA IDO A ESCUCHARLO EN UN CLUB AHORA ESTABA GRABANDO AQUEL REPERTORIO CON SU PROPIA PERSONALIDAD. //

PERO LA HISTORIA TODAVÍA GUARDABA ALGO MEJOR. //

EN LOS PRIMEROS AÑOS SETENTA, CAREY VOLVIÓ A ENCONTRARSE MUSICALMENTE CON BIG WALTER HORTON. //

LOS DOS GRABARON JUNTOS PARA ALLIGATOR. //

Y ACÁ QUIERO DETENERME. //

PORQUE HAY MUCHOS DISCOS DONDE UN MÚSICO JOVEN COMPARTE ESTUDIO CON UNO MAYOR. //

PERO NO TODOS TIENEN DETRÁS UNA RELACIÓN COMO ESTA. //

CAREY HABÍA ADMIRADO A BIG WALTER DESDE QUE ERA CHICO. //

LO HABÍA ESCUCHADO. //

LO HABÍA SEGUIDO. //

HABÍA APRENDIDO DE ÉL. //

Y AHORA LOS DOS ESTABAN GRABANDO. //

NO ERA SOLAMENTE UN ENCUENTRO ENTRE DOS ARMONICISTAS. //

ERA UNA RELACIÓN DE AÑOS QUE HABÍA LLEGADO AL ESTUDIO. //

CAREY TAMBIÉN TRABAJÓ CON MUDDY WATERS Y WILLIE DIXON. //

Y CON EL TIEMPO SE CONVIRTIÓ EN UNO DE LOS ARMONICISTAS MÁS RESPETADOS DE CHICAGO. //

EN 1990 PARTICIPÓ EN UN PROYECTO MUY ESPECIAL. //

HARP ATTACK! //

CUATRO GRANDES ARMONICISTAS EN UN MISMO DISCO. //

JUNIOR WELLS. /

JAMES COTTON. /

BILLY BRANCH. /

Y CAREY BELL. //

CUATRO PERSONALIDADES. //

CUATRO MANERAS DE TOCAR. //

Y UNA MISMA TRADICIÓN MUSICAL. //

PERO QUIERO CONTARTE OTRA PARTE DE SU VIDA. //

UNA QUE ME PARECE PARTICULARMENTE LINDA. //

SU RELACIÓN CON SU HIJO LURRIE BELL. //

LURRIE CRECIÓ RODEADO DE MÚSICA. //

SU PADRE TOCABA CON ALGUNOS DE LOS HOMBRES MÁS IMPORTANTES DEL BLUES. //

Y ÉL MISMO TERMINÓ CONVIRTIÉNDOSE EN UN GRAN GUITARRISTA. //

PERO LA VIDA DE LURRIE NO FUE SENCILLA. //

ATRAVESÓ PROBLEMAS PERSONALES Y DE SALUD. //

Y LA RELACIÓN ENTRE PADRE E HIJO TUVO QUE CONVIVIR CON ESAS DIFICULTADES. //

SIN EMBARGO, LA MÚSICA SIGUIÓ SIENDO UN LUGAR DONDE PODÍAN ENCONTRARSE. //

EN 1991 COMPARTIERON UNA GIRA POR FINLANDIA. //

IMAGINATE LA DISTANCIA. //

DOS MÚSICOS FORMADOS EN LA TRADICIÓN DEL BLUES DE CHICAGO, VIAJANDO POR UN PAÍS DEL NORTE DE EUROPA. //

EN PLENO INVIERNO. //

TOCANDO EN LUGARES QUE ESTABAN A MILES DE KILÓMETROS DEL MISSISSIPPI. //

Y SIN EMBARGO, LA MÚSICA FUNCIONABA. //

LA GENTE ESCUCHABA. //

SE EMOCIONABA. //

Y EN AQUELLOS CONCIERTOS QUEDARON REGISTRADAS INTERPRETACIONES QUE AÑOS DESPUÉS SE PUBLICARÍAN EN SECOND NATURE. //

EL TÍTULO ES MUY APROPIADO. //

SEGUNDA NATURALEZA. //

ALGO QUE UNO HACE CASI SIN PENSARLO PORQUE FORMA PARTE DE SU VIDA. //

Y PARA CAREY Y LURRIE, TOCAR BLUES JUNTOS TENÍA ALGO DE ESO. //

PADRE E HIJO COMPARTÍAN UNA MÚSICA QUE HABÍA ACOMPAÑADO A LA FAMILIA DURANTE DÉCADAS. //

CAREY MURIÓ EL 6 DE MAYO DE 2007. //

TENÍA 70 AÑOS. //

Y HABÍA RECORRIDO UN CAMINO EXTRAORDINARIO. //

DEL CHICO QUE QUERÍA UN SAXOFÓN Y TERMINÓ CON UNA ARMÓNICA... //

AL JOVEN QUE VIAJÓ A CHICAGO PARA CONOCER A SUS ÍDOLOS... //

AL MÚSICO QUE TUVO QUE APRENDER EL BAJO PARA PODER TRABAJAR... //

Y FINALMENTE, AL PADRE QUE COMPARTIÓ SU MÚSICA CON SU HIJO. //

HAY ALGO QUE ME GUSTA MUCHO DE ESTA HISTORIA. //

CAREY NO CONSIGUIÓ EL INSTRUMENTO QUE QUERÍA. //

PERO CON EL QUE TUVO CONSIGUIÓ CONSTRUIR UNA VIDA ENTERA. //
