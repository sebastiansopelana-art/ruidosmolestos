ANTES DE LA TAPA DE UN DISCO ESTÁ ESA POSIBILIDAD. / PROBAR UNA VOZ JUNTO A OTRA. / VOLVER A EMPEZAR CUANDO NO SALE. / DESCUBRIR QUE EL OTRO ENTIENDE ALGO QUE A UNO LE COSTABA EXPLICAR. //

CHARLY TRAÍA LA FORMACIÓN DEL PIANO Y EL IMPACTO DE LOS BEATLES. / NITO, SU VOZ, LA GUITARRA, LA FLAUTA. / SUI GENERIS TUVO UNA FORMACIÓN MÁS AMPLIA ANTES DE QUEDAR EN LA IMAGEN QUE TODOS RECONOCEMOS: / DOS MUCHACHOS DE PELO LARGO. / CUANDO NITO RECUERDA EL COMIENZO DE 1972 EN MAR DEL PLATA, / CUENTA QUE PARA AQUEL DEBUT YA QUEDABAN ELLOS DOS. //

PIENSO EN LA DISTANCIA QUE HAY ENTRE ESA FRAGILIDAD Y LA SEGURIDAD CON LA QUE HOY DECIMOS SUI GENERIS. / LO PRONUNCIAMOS COMO SI HUBIERA ESTADO DESTINADO A OCURRIR. / PERO UN GRUPO QUE RECIÉN EMPIEZA NO TIENE GARANTIZADO EL PRÓXIMO ESCENARIO. / TIENE CANCIONES Y LAS GANAS DE QUE ALGUIEN SE QUEDE A ESCUCHARLAS. //

EN 1972 LLEGÓ VIDA. / HAY UNA ANÉCDOTA DE LA GRABACIÓN QUE NITO RECORDÓ AÑOS DESPUÉS. / LAS SESIONES ENTRABAN EN LOS HUECOS QUE DEJABAN OTROS MÚSICOS, / A VECES EN HORARIOS MUY TEMPRANOS. / UNA MAÑANA, / CANTANDO CANCIÓN PARA MI MUERTE, / SE LE ESCAPÓ UN GALLO. //

AHÍ ESTÁ EL CUERPO DETRÁS DE UNA GRABACIÓN QUE DESPUÉS PARECE INTACTA. / LA GARGANTA A UNA HORA INGRATA. / EL ESFUERZO POR HACER UNA TOMA. / DOS MÚSICOS TRATANDO DE APROVECHAR EL TIEMPO QUE TIENEN. / ME GUSTA QUE ESE RECUERDO HAYA SOBREVIVIDO JUNTO A LAS CIFRAS Y LOS GRANDES TÍTULOS. / PORQUE NOS PERMITE ACERCARNOS. //

Y AHORA PENSÁ EN EL CAMINO QUE HIZO ESA CANCIÓN. / DE UNA SESIÓN DE GRABACIÓN A UNA CASA. / DE ESA CASA A UNA GUITARRA. / DE UNA GUITARRA A OTRA REUNIÓN. / ALGUIEN APRENDE LOS ACORDES Y LA LLEVA A UN LUGAR DONDE CHARLY Y NITO NUNCA ESTUVIERON. //

UNO PUEDE QUERER MUCHO UNA ETAPA Y NECESITAR IRSE DE ELLA. / HAY ALGO DE ESA INQUIETUD QUE VA A REPETIRSE EN SU CARRERA. / CADA VEZ QUE PARECE QUE YA SABEMOS QUÉ ESPERAR, / APARECE OTRA PUERTA. //

ESA PUERTA TAMBIÉN TUVO NOMBRE DE PERSONA: / DAVID LEBÓN. //

CHARLY Y DAVID. / MORO Y PEDRO. / SERÚ GIRÁN. //

HOY ES FÁCIL PONER ESOS CUATRO NOMBRES JUNTOS Y ASENTIR. / PERO EL COMIENZO TUVO TROPIEZOS. / EN ESA ENTREVISTA TAMBIÉN RECORDARON LA DUREZA DE LAS PRIMERAS CRÍTICAS, / EL TRABAJO DE VOLVER A CONSEGUIR ACTUACIONES, / LA NECESIDAD DE GANARSE UN LUGAR. //
